할리갈리 데스런 환경 제작안

기본 맵: 낡은 건물의 실내
색: 바랜 회녹색 도장, 회색 콘크리트, 어두운 강철, 은은한 형광등.
소품: 동일한 합판 의자, 넓고 낮은 카드 테이블, 황동 종,
철제 발판, 벽 패널, 바닥 패널, 지지 기둥, 형광등, 배관.
카드와 턴 화살표가 잘 보이도록 테이블 면은 평평하고 충분히 밝게 유지한다.

등산 맵: 바위턱을 밟아 정상의 종까지 올라가는 산
색: 회색 화강암, 바위틈의 어두운 이끼, 소나무, 옅은 회청색 안개.
추가 소품: 착지면이 넓고 거의 평평한 바위턱, 갈라진 수직 암봉, 소나무.
기존 등산 경로 주변을 바위 절벽으로 연출하고, 먼 산 능선을 암봉 인스턴스로 구성한다.
소나무는 플레이 경로 밖에 배치한다. 정상의 종을 시각적 목표로 둔다.

Unity 적용 기준
1. 카드, 캐릭터, 손, 모션, 타격, 카드 턴 화살표는 유지한다.
2. 모든 의자는 같은 모델을 공유한다.
3. 기존 Collider와 경로 앵커를 보존하고 외형 Renderer만 교체한다.
4. 2~6명 변경 시 의자와 첫 발판이 기존 CourseRoster를 따라 이동한다.
5. 공유 발판 폭이 변할 때 외형도 같이 변하도록 기존 발판의 자식으로 연결한다.
6. 바위의 울퉁불퉁한 장식은 착지면의 높이와 발판 가장자리를 오해하게 만들지 않아야 한다.
7. 테이블 상단은 기존 카드 면보다 아래에 맞춘다.
8. 원본 GLB와 제작 노드 ID를 보존하고 FBX/PBR 텍스처로 변환한다.
9. 원본 장면을 백업하고, 설치 전후 충돌체·앵커 상태를 비교한다.
10. 두 맵의 실제 게임 화면과 카드 위 시점을 확인한 뒤 기존 규칙/인원/맵 검증을 수행한다.

현재 제작 상태
실내 소품 9종의 레퍼런스 이미지 생성 완료.
실내 9종과 산 3종의 VARCO 노드 연결 완료.
사용자가 추가 2,460포인트 사용을 승인한 뒤 12종 3D와 산 시안 3종 생성 완료.
Unity 기본맵과 등산맵에 모델·PBR 재질·배경·조명을 적용했다. 콜라이더와 경로 앵커 보존 검증 통과.

승인한 추가 생성의 예상 사용량
실내 9종 3D: 9 x 200 = 1,800포인트
산 3종 이미지: 3 x 20 = 60포인트
산 3종 3D: 3 x 200 = 600포인트
합계: 2,460포인트
이미 완료된 실내 시안 9종의 예상 180포인트는 위 합계에서 제외.
단가는 준비 시점의 VARCO 계정/가격 조회 결과 기준.
