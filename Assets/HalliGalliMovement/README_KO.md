# 할리갈리 데스런 — Bell Run 코스 프로토타입

Unity 6 프로젝트입니다. `Demo/BellRunCourse.unity`를 열고 Play를 누르면 시작 화면에서 방 만들기 / 초대코드로 참가 / 연습실을 선택할 수 있습니다. 혼자 하고 싶으면 방을 만들고 AI를 한 명씩 추가합니다. 기존 이동 테스트 씬은 `Demo/MovementLab.unity`에 있습니다. 기존 프로젝트에는 `Exports/HalliGalliMovement.unitypackage`를 가져오면 됩니다.

사용자 맵은 시작 화면의 **맵 만들기**에서 제작합니다. **F8 클리어 검증**에서 혼자 출발점부터 이동해 **E로 도착 종을 울린 뒤** 편집기로 돌아와 저장합니다. 검증 중 낙하/R은 체크포인트 없이 처음부터 재도전하며 수정하면 인증이 해제됩니다. 방의 **사용자 맵**에서 내 맵 또는 받은 맵을 선택하면 참가자에게 자동 전달합니다. 다운로드한 맵은 보관되어 재실행 후에도 재클리어 없이 방을 만들 수 있고, 정확히 같은 내용이 있으면 캐시를 사용합니다. `.bellmap` **가져오기**도 원본을 받은 맵에 보관하며 별도의 편집 초안을 엽니다. 받은 원본은 그대로 재공유할 수 있지만 수정한 초안은 직접 클리어해야 저장·공유됩니다. 자세한 조작·제약은 루트 `README.md`와 `Docs/HANDOFF.md`를 확인하세요.

맵 편집 카메라는 기본적으로 위에서 내려다봅니다. 빈 바닥 드래그로 화면 이동, 휠/−/＋로 줌, 부품 클릭은 선택, 더블클릭은 가까이 보기입니다. 편집은 선택한 부품의 손잡이를 드래그합니다. 위/사선/옆 및 전체/선택/출발점/도착 종 버튼으로 위치를 찾고, 자유 비행이 필요할 때만 고급 비행을 켜세요. F8 테스트에서 돌아오면 편집 시점이 유지됩니다.

부품 목록은 왼쪽 두 번째 줄의 금색 **부품 메뉴** 안에 있습니다. 필요한 때 열고 부품을 고르면 자동으로 닫혀 맵을 넓게 볼 수 있습니다. 버튼/Esc/맵 영역 클릭으로도 닫습니다.

부품에는 콘크리트·금속·고무 표면과 장치별 디테일이 자동 적용됩니다. 색상은 장식 포인트를 바꿉니다. 공식 맵과 사용자 맵의 바닥 면적 표시용 테두리는 체크포인트만 남기며, 충돌 크기와 코스 동작은 유지합니다.

마지막 공식 맵 **아이템 레이스**는 220m 연속 트랙과 32개 아이템 박스를 제공합니다. 박스를 통과하면 선두는 5초 방어막, 나머지는 유도 미사일/바나나를 랜덤 획득합니다. 하나씩 보관하고 **C**로 사용합니다. 앞쪽 상대를 조준해 미사일을 락온하고, 바나나는 뒤에 설치합니다. 미사일 피격 시 몸만 공중제비를 돌고 1인칭 카메라는 뒤집히지 않습니다. 방어막은 두 공격을 막습니다. 박스는 8초 후 재등장하며 카드·종 규칙은 그대로입니다.

## 종까지의 짧은 장애물 코스

테이블 뒤쪽의 카드 공간과 일렬 의자 → 공통 출발선 → 좌석별 첫 발판 → 넓은 합류 발판 → 좁은 중앙 발판 → 체크포인트 대기 구역 → 앞뒤로 왕복하는 운반 발판 → 종 도착 발판으로 이어집니다. 발판에는 난간이 없으며 발차기 넉백으로 상대를 떨어뜨릴 수 있습니다.

모두 앉아 있고 내 차례일 때 좌클릭으로 한 장을 공개합니다. 같은 과일이 정확히 5개인지 직접 판단한 뒤 E로 일어나세요. 처음 누군가 일어나는 순간 카드 공개를 멈춥니다. 잘못 일어나면 다른 생존 참가자마다 비공개 카드 한 장을 지급하고, 자기 자리에서 E로 다시 앉아야 합니다. 자동으로 앉히지 않으며 추락해도 복귀 의무가 유지됩니다. E와 좌클릭이 동시에 들어오면 기립이 먼저 적용됩니다.

로컬 AI 1~5명은 자기 턴에 약 1.2초 뒤 공개하고, 5개를 발견하면 약 0.9초 뒤 출발합니다. 같은 이동 물리로 달리고 점프하며 가까이 있으면 반격합니다. 추락하면 0.7초 뒤 코스 입구에서 재시작합니다. 잘못 기립한 상태에서 추락하면 의자 옆으로 돌아옵니다. 종 앞에서 E를 누르면 모든 공개 더미를 획득하고, 참가자 전원이 자기 자리에 즉시 앉습니다. 추락 중이던 참가자의 복귀 예약도 취소하며, 역방향으로 뛰어오는 구간 없이 획득자부터 다음 공개 턴을 시작합니다. 1대1은 비공개 카드가 떨어지면 즉시 패배합니다. 3인 이상으로 시작한 대결에서만 마지막 카드를 공개한 뒤에도 공개 더미를 잃기 전까지 경쟁할 수 있고, 한 명만 남아 모든 카드를 가지면 최종 승리합니다.

카드가 공개되면 `CourseTableView`가 0.22초 동안 책상 위 시점으로 전환하고, 참가자들의 공개 카드와 비공개 덱을 화면 안에 맞춥니다. 카드 판단 중에는 이 시점을 유지하고 E로 일어나는 즉시 이동용 1인칭 시점·시야각·마우스 조작을 복원합니다. 손 카메라는 책상 시점 동안 숨겨 카드를 가리지 않습니다. 캐릭터 몸과 충돌체는 의자에 그대로 있으며 카메라만 이동합니다. 4:3, 16:9, 21:9 화면 비율에서 카드 모서리 가시성을 검사합니다. 잘못 기립한 경우에는 여전히 자기 자리에서 직접 E로 앉아야 합니다.

`CourseRoster`가 2~6인을 배치합니다. 방 정원은 6명으로 고정이며 실제로 입장한 사람과 직접 추가한 AI만 참가합니다. 3명으로 시작하면 3인전이고 빈자리는 자동으로 채우지 않습니다. 의자는 1.5m 간격의 일렬이고 테이블을 뒤쪽에 놓아 진입 경로를 비웠습니다. 공개 더미는 같은 반지름의 원에 균등 각도로 놓고, 비공개 더미는 바깥 원에 놓습니다. 번호와 색상이 좌석·카드·레인을 연결합니다. 책상 카메라는 전체 카드 배치에 맞춰 화면을 잡습니다.

모든 출발 앵커는 Z=-0.7m, 첫 발판 중심은 Z=2.3m이며 X는 자신의 좌석과 같습니다. 따라서 수평 중심 거리는 모두 3m, 출발 데크 끝부터 착지면까지의 빈틈은 1.3m, 첫 발판 높이는 0.15m입니다. 첫 발판은 폭 1.3m × 길이 2m이고 합류 발판도 자리별 정면에서 진입합니다. 이 수치는 시작 구간에 대한 동일 조건이며 합류 이후 종까지의 전체 이동 거리는 다를 수 있습니다. AI는 사람뿐 아니라 가까운 다른 AI도 공격합니다. 새 카드가 공개된 프레임에 뒤 순서 AI가 즉시 출발하지 않도록 공개 후 반응 시간을 다시 시작합니다.

카드는 `Assets/HalliGalliCards`의 기본판 56장을 사용합니다. `HalliGalliMatch`가 2~6인의 덱, 공개 더미, 차례, 기립 판정, 페널티, 획득과 승리를 관리하고 `CourseCardGame`이 좌석·입력·종·AI와 연결합니다. `CardTableDisplay`는 고유 카드 56장의 실제 위치와 앞뒷면을 갱신합니다. 공개는 즉시 적용하여 판정과 화면의 카드가 다르지 않게 했습니다. 자동으로 5개 정답을 알려 주는 UI는 없습니다. 로컬 2~6인 대결과 Unity Lobby·Relay를 사용하는 온라인 대결을 지원합니다. 방 만들기, 초대 코드 옆 복사, 코드로 입장, 준비 완료 후 방장 시작을 사용할 수 있습니다. 모든 친구가 같은 최신 빌드를 사용해야 합니다.

## 조작

시작 화면·대기방·게임 중 Esc 메뉴의 **조작키 설정**에서 바꿉니다. 각 동작에 최대 세 개의 입력을 지정할 수 있으며 변경은 이 PC에 자동 저장됩니다. 키가 겹치면 서로 바꿀지 선택하고, ×로 해제하거나 기본값을 복원할 수 있습니다. Esc와 메뉴 클릭은 고정입니다. 아래 표는 기본값입니다.

점프는 기본적으로 **Space + 휠 아래**입니다. `휠 양방향 점프`를 누르면 휠 위도 추가합니다. 휠 입력은 한 번씩 점프를 요청하며, 자동 연속 점프를 켜지 않습니다. 착지 타이밍에 굴려 기존 점프 버퍼를 사용할 수 있습니다.

| 입력 | 동작 |
| --- | --- |
| WASD | 시선 방향을 기준으로 이동 |
| 마우스 | 좌우 회전 및 위아래 시점 |
| Q | 밧줄 투척 / 다시 눌러 당기기 (누르는 순간 마우스를 휘두르면 그 방향으로 던지기) |
| C | 아이템 레이스에서 보유 아이템 사용 |
| Space / 휠 아래 | 점프 |
| Ctrl 누르기 | 웅크리기 |
| 마우스 좌클릭 | 왼손·오른손 번갈아 주먹질 / 앉았을 때 카드 공개 |
| F | 오른발 앞차기 |
| Esc / 화면 클릭 | 커서 해제 / 조작 재개 |
| E | 자리에서 일어나기 / 종 울리기 / 내 자리 근처에서 앉기 |
| R | 최근 체크포인트로 복귀 / 경기 종료 후 새 게임 |
| V | 1인칭 / 전신 확인 시점 전환 |
| H / J | MovementLab에서 자신에게 주먹 / 발차기 피격 적용 (테스트) |

Ctrl은 이동용 웅크리기, E는 테이블 좌석 상호작용입니다. 앉아 있거나 추락 후 복귀 중이면 공격을 받거나 실행하지 않습니다. 좌석용 Seated 모션은 별도로 직접 제작했습니다.

## 움직임

- 지상에서 가속하고 마찰로 감속합니다. 대각선 이동으로 기본 속도가 늘어나지 않습니다.
- 공중에서 지상 마찰을 적용하지 않고 관성을 유지합니다. 입력 방향의 속도 성분을 제한하는 공중 스트레이프를 사용합니다.
- 점프 직전에 지상 마찰을 생략하여 달리던 관성을 유지합니다.
- 자동 버니합은 기본적으로 꺼져 있습니다. Space를 다시 눌러야 다음 점프가 나갑니다. 착지 직전 0.08초 이내의 점프 입력은 기억합니다.
- 웅크리는 동안 속도와 충돌체 높이가 줄어듭니다. 천장이 낮으면 Ctrl을 놓아도 일어서지 않습니다.
- 공중 웅크리기는 머리 높이를 유지하며 다리를 당깁니다. 위로 향하는 속도를 추가하지 않습니다.
- 계단, 경사, 벽을 따라 미끄러지기, 머리 충돌, 낙하와 착지를 처리합니다.
- 0.015초 고정 간격으로 이동을 계산하고, 시점 위치를 보간합니다. 마우스 회전에 프레임 시간을 곱하지 않습니다.
- 현재 입력 설정은 Unity 기본 Input Manager입니다. Input System이 활성화된 프로젝트에서는 조건부 코드가 Keyboard/Mouse 입력을 읽습니다.

## 조정

`Settings/DefaultMovement.asset`에서 값을 바꿀 수 있습니다.

| 항목 | 기본값 |
| --- | --- |
| 기본 이동 / 웅크리기 | 4.5 / 2.2 m/s |
| 점프 높이 / 중력 | 1 m / 20 m/s² |
| 지상 가속 / 마찰 | 14 / 7 |
| 공중 가속 / 방향별 속도 한도 | 12 / 0.8 m/s |
| 서기 / 웅크리기 높이 | 1.8 / 1.0 m |
| 계단 높이 / 보행 가능한 경사 | 0.3 m / 46° |
| 마우스 감도 / 수직 시야각 | 0.12 / 85° |

공중 방향별 속도 한도는 전체 이동 속도의 상한이 아닙니다. `maximumAirSpeed`가 0이면 공중 스트레이프로 속도를 더 얻을 수 있습니다. 경쟁 규칙에 맞춰 이 값을 제한할 수 있습니다.

## 구성과 연결

- `SourceMotor`: 이동, 충돌, 중력, 점프, 웅크리기. `AddImpulse`로 타격 밀치기를 받습니다.
- `SourcePlayerController`: 키보드/마우스 입력과 1인칭 카메라. 입력을 모터와 분리했습니다.
- `SourcePlayer.prefab`: 전신 캐릭터, 실사풍 양손, 카메라와 모션 연결이 포함된 플레이어 프리팹.
- `CharacterMotionDriver`: 실제 이동 속도, 지면 접촉, 수직 속도, 충돌체 높이를 읽어 모션을 전환합니다. 애니메이션은 이동 모터를 움직이지 않습니다.
- `Art/CustomMotions.asset`: 전신 25개, 손 16개의 직접 제작한 모션 클립과 전환 시간.
- `MeleeCombat` / `MeleeReceiver`: 공격 입력, 타격 시점, 가장 가까운 표면 판정, 1회 타격, 밀치기. 플레이어 프리팹에 연결되어 있습니다.
- `TrainingOpponent` / `HitReactionAnimator`: 주먹에는 방향별로 휘청이고 발차기에 밀려나는 연습 상대. 마지막 피격 3초 뒤 돌아옵니다.
- `Audio/ImpactSounds.asset`: 주먹·발차기 효과음 각 3개. 플레이어와 연습 상대의 3D AudioSource에 연결됩니다.
- `Art/Motions`: Unity Animation 창에서 편집 가능한 .anim 파일. 걷기·달리기·웅크린 이동은 전후좌우 방향을 포함합니다.
- `Editor/MotionPoseAuthor`: 자세와 보폭, 팔 흔들림, 손가락 굽힘을 정의하는 제작 원본입니다. `HalliGalli > Prepare Character Assets`로 클립을 다시 만들면 기존 .anim 수정 사항을 덮어씁니다.
- `MovementLab`: 가속 구간, 계단, 경사, 낮은 통로, 점프 발판, 낙하 후 복귀가 있는 테스트 맵.
- `Tests/MovementValidationRunner`: 실제 Unity 플레이 모드에서 이동과 물리 충돌을 검증합니다. 배포 빌드에서는 제외됩니다.
- `Editor/MovementProjectBuilder`: 데모 생성, 검증, 패키지 및 Windows 테스트 빌드를 준비합니다.

플레이어 루트의 스케일은 (1,1,1), 회전은 Y축 회전만 사용합니다. Rigidbody는 추가하지 않습니다. 발밑이 루트 위치이며 CharacterController의 중심은 높이의 절반입니다.

전신은 기존 대머리 캐릭터를 사용합니다. 1인칭 손은 V3로 교체했습니다. 손바닥을 기준으로 새 원형을 만들고, 손등과 손바닥을 별도 참고 이미지로 작업해 4K 텍스처로 합쳤습니다. 이전 모델의 손바닥 쪽 손톱과 과도한 가죽 요철은 사용하지 않습니다. 양손은 34개 뼈(손가락 30개), 116,102 삼각형이며 가까이 보이는 1인칭용입니다. 관절 주변의 변형 연결을 부드럽게 만들고 엄지의 접힘 방향을 조정했습니다. 카메라 안에 팔 끝이 보이지 않도록 1인칭 사용본의 팔 부분을 연장했습니다. 전신은 기존 53개 뼈를 유지합니다.

`Previews/Hands_Review.png`는 실제 모델의 손등·손바닥·굽힘 비교입니다. `Previews/Hands_Grip.gif`는 Unity에서 같은 관절 규칙을 적용한 연속 굽힘입니다. Blender 원본에는 Hand_Open, Hand_Relaxed, Hand_Fist, Hand_GripCycle 액션을 별도로 넣었습니다. 자동 이동 검사는 작동 확인이며 외형 검수와는 별개입니다.

모션은 자체 자세 계산으로 만들고 .anim으로 구웠습니다. VARCO 애니메이션은 가져오지 않습니다. Legacy Animation 컴포넌트가 부드럽게 전환하므로 별도 Animator Controller가 필요하지 않습니다. 걷기 모션의 고개 흔들림은 없으며, 주먹 피격 시 방향에 따른 화면 휘청임을 적용합니다.

카메라는 Built-in 렌더러를 사용합니다. 레이어 8은 로컬 전신, 레이어 9는 1인칭 손·발 전용입니다. 손 카메라는 깊이만 지운 후 손과 공격하는 발을 따로 그려 벽에 가려지는 문제를 줄이며 전신 확인 시에는 비활성화됩니다. 다른 프로젝트에 가져올 때는 해당 레이어의 용도와 렌더 파이프라인을 맞추세요.

카드 판정, 좌석 상태, 종 누르기는 BellRunCourse와 ClimbCourse에 연결되어 있습니다. 체력, 멀티플레이 동기화, 움직이는 발판 및 사다리는 구현하지 않았습니다.

## 맵 선택과 등산 코스

Esc → 맵 선택에서 현재 인원을 유지하며 새 대결을 시작합니다. `BellRunCourse`는 **첫걸음 / 입문 1단계**, `ClimbCourse`는 **정상 쟁탈 / 어려움 3단계**, `SurfCourse`는 **서프 수로 / 어려움 4단계**입니다. 정밀 점프는 제작 예정이며 선택되지 않습니다. 같은 맵을 다시 선택해도 새 게임이 시작됩니다.

정상 쟁탈은 하나의 봉우리를 한 바퀴 돌아 올라가는 공통 코스입니다. 본길에는 얕은 착지점, 절벽을 따라 놓인 좁은 바위턱, 높이가 다른 대각선 점프가 섞여 있습니다. 넓은 입구·체크포인트·쉼터에서는 상대 옆으로 지나갈 수 있지만, 노출된 구간에서 점프를 놓치거나 바깥쪽으로 밀리면 추락합니다. 중간 두 곳에는 안쪽 모서리를 질러가는 좁은 숏컷 발판이 있습니다. 본길의 세 번 점프를 두 번으로 줄이고 곧바로 같은 길에 합류합니다. 중앙의 CHECK 발판에 착지하면 추락 후 그곳에서 복귀합니다. 정상의 종을 누르면 기존 카드 규칙에 따라 모두 즉시 착석합니다.

구조 참고: CS:S [xc_peak](https://gamebanana.com/mods/123773), CS2 [kz_kzro_mountainsein](https://steamcommunity.com/sharedfiles/filedetails/?id=3656317465)의 암벽과 돌출 발판 구성. 원본 맵 파일을 가져오지 않고 기존 VARCO 에셋과 별도의 코스 지형으로 제작했습니다.

각 참가자의 남은 카드는 뒷면 카드뭉치의 두께로 나타냅니다. 공개·기립 페널티·종 획득·새 게임에 맞춰 두께가 갱신됩니다. 카드 공개 시 책상 위를 살짝 기울여 바라보므로 과일과 카드뭉치의 옆면을 함께 볼 수 있습니다.

`Maps/CourseMaps.asset`가 목록, 각 `CourseMapDefinition`이 이름·종류·난이도·설명·씬 경로·이동 프로필을 보관합니다. `CourseMapController`는 실제 씬을 바꾸고 선택 인원을 넘깁니다. 플레이 가능으로 등록된 씬만 빌드에 포함하며, 예정 항목은 씬 로드나 현재 대결 초기화를 할 수 없습니다. 맵 변경 시 현재 카드 대결은 초기화됩니다.

새 코스는 공통 테이블·6인 입구를 유지하는 별도 씬으로 만들고, `CourseRoster.routeRoots`의 첫 두 착지점 이후 경로와 종 위치를 작성합니다. `CourseMapDefinition`을 생성하여 목록에 추가하고 씬의 `CourseMapController.current`를 연결합니다. 각 맵의 플레이어와 AI는 같은 이동 프로필을 사용합니다. `HalliGalli > Maps > Install Maps and Build Climb`는 등산 씬이 없을 때만 생성하므로 이미 손본 등산 씬을 덮어쓰지 않습니다.

등산 씬의 `CourseRoster.branches`는 `CourseBranchRoutes`를 참조합니다. `sharedSpiral` 모드에서 `left`와 `right`는 동일한 11개 착지점을 공유하며 `summit`은 중앙 정상입니다. `shortcuts`는 진입·합류 지점과 숏컷 발판을 기록합니다. AI는 앞쪽 착지점을 상대가 막으면 숏컷을 선택하고 실제 이동과 점프로 통과합니다. `ClimbStep`은 AI 입력을 안내하며 플레이어에게 힘이나 자동 점프를 적용하지 않습니다. 인원 변경 시 첫 두 착지점은 유지합니다. `HalliGalli > Maps > Build Spiral Summit`는 씬을 백업하고 코스를 재생성한 뒤 기존 VARCO 산 모델을 적용합니다.

## 서프 수로

직진 활주 → 낮은 회전 발판으로 낙하 → 마우스로 180도 회전 → 상층 아래를 역방향으로 활주 → 오른쪽 곡선 → 두 차례 연속 커브 → 반대편 뱅크 전환 → 70도 좌회전 → 좁은 경사면과 5m 공중 연결 → 110도 상승 곡면 → 떨어진 종 발판 순서입니다. 회전 발판의 착지 위치, 곡선의 안쪽과 바깥쪽 선택, 공중 조향에 따라 시간 차이가 납니다. 마지막 도약은 경사면과 충돌한 실제 속도에서 나옵니다. 속도가 부족하면 종 발판에 닿지 않으며 자동 발사나 가속 보정은 없습니다. 출발선과 첫 발판까지 거리는 동일합니다.

진행 방향을 바라볼 때 왼쪽 면은 A, 오른쪽 면은 D로 면 쪽을 누르며 활주합니다. 진입 후 W를 놓고 마우스로 부드럽게 조향합니다. 끝에서 면을 벗어나면 관성이 이어지고 다음 경사면을 받을 수 있습니다. 경사면에서는 지상 점프가 발동하지 않습니다. 공중 주먹과 발차기, 추락 복귀, 종 획득 후 즉시 착석은 기존 시스템을 사용합니다.

`SurfMovement.asset`은 `surfEnabled=true`, `airAcceleration=80`, `airWishSpeedCap=0.8`, 공중 속도 상한 없음으로 설정합니다. PhysX의 경사 제한만 90도로 열고, 실제 접지 판정은 기존 46도 기준을 사용합니다. 급경사 접촉에서는 지상 마찰과 스냅을 적용하지 않고 속도를 충돌면에 투영합니다. 첫걸음과 등산맵은 기본 프로필을 유지합니다.

`SurfCourse`는 AI의 경사면 진입 위치와 좌우 조향 입력을 계산합니다. AI 역시 같은 `SourceMotor`로 움직이며, 활주 중 위치 강제 보정이나 자동 가속 장치를 사용하지 않습니다. 메시와 외형은 `SurfCourseBuilder`로 생성하며 VARCO 콘크리트 재질의 정상 UV 영역과 기존 실내 프리팹을 재사용합니다. `HalliGalli > Maps > Build Surf Course`는 기존 서프 씬을 백업한 뒤 다시 생성합니다.

공중 가속과 충돌면 속도 투영은 [Valve Source SDK 이동 코드](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/shared/gamemovement.cpp)의 동작을 참고했습니다. 이 Unity 구현은 CS의 완전한 물리 복제는 아닙니다.

서프 구간 끝의 보라색 선 11개를 순서대로 지나야 종을 울릴 수 있습니다. 첫 직선 아래의 감전 칸막이는 출발대 아래와 옆·뒤 낙하 공간까지 덮습니다. 출발 구역의 양옆·뒤를 격벽으로 둘러, 바로 아래 두 번째 활주면으로 떨어지는 길도 막습니다. 끝의 180도 회전 착지장은 열려 있습니다. 초반과 후반 사이에는 바닥부터 천장까지 격벽이 있고 정상 외곽 커브가 지나는 개구부만 열려 있습니다. 격벽은 몸을 막고, 전기가 흐르는 가로 칸막이는 접촉 시 복귀시킵니다. 기존 VARCO 벽·바닥 자산을 재사용하며, 각 격벽의 충돌면은 하나로 구성합니다. `HalliGalli > Maps > Install Surf Divider`는 현재 서프 씬을 백업하고 감전 칸막이와 격벽을 갱신합니다.

회전 착지장·첫 곡면 도약 뒤 착지장·반대편 뱅크 전환 착지장의 체크포인트는 해당 구간을 통과하고 착지해야 저장됩니다. 추락과 R 복귀 시 저장된 통과 기록을 복원하고, 착석하면 초기화합니다.

칸막이는 어두운 전극 격자와 노랑·검정 경계선, 반복되는 번개 경고 문양으로 구분합니다. `SurfDividerElectricity`가 표면 가까이에서 서로 다른 타이밍으로 푸른 방전을 표시합니다. 경고 무늬는 항상 보이며 전체 화면 점멸이나 추가 광원은 없습니다. 표시용 메시와 전기에는 충돌체가 없습니다.

칸막이에 몸이 닿으면 `SurfDivider`가 기존 추락 복귀를 시작합니다. 방장이 접촉을 판정하고 참가자에게 동기화합니다. 마지막 체크포인트가 없으면 출발점으로 돌아가며, 카드와 밧줄 쿨타임은 초기화하지 않습니다. 접촉하지 않고 가까이 지나가는 것만으로 복귀시키지는 않습니다.

## 주먹질과 발차기

좌클릭은 왼손부터 시작하고 실제 접수된 공격마다 좌우가 번갈아 나갑니다. F는 오른발 앞차기이며 주먹 순서에는 영향을 주지 않습니다. 누르고 있어도 자동 반복하지 않습니다. 준비 동작 중 추가 입력은 받지 않으며, 회수 마지막 0.16초에 다음 공격 한 번을 예약할 수 있습니다. F와 좌클릭을 같은 프레임에 누르면 F가 우선합니다. R은 공격과 좌우 순서도 초기화합니다.

| 항목 | 주먹 | 발차기 |
| --- | --- | --- |
| 준비부터 회수까지 | 0.42초 | 0.72초 |
| 타격 판정 시간 | 0.14–0.22초 | 0.27–0.38초 |
| 구체 판정 이동 거리 / 반지름 | 1.25m / 0.18m | 1.65m / 0.22m |
| 밀치기 속도 변화: 수평 / 위 | 없음 | 6 / 4m/s |
| 이동·점프·공격 입력 중단 | 없음 | 0.12초 |
| 피격 모션 길이 | 0.48초 | 0.42초 |
| 피격 화면 휘청임 | 0.45초 후 복귀 | 없음 (실제 넉백으로 이동) |

판정은 시선 방향을 따릅니다. 가장 가까운 고체 표면이 공격을 막고, 한 공격에서 한 대상만 한 번 타격합니다. 트리거와 자기 자신의 충돌체는 제외합니다. 대상 충돌체 두께와 판정 반지름 때문에 중심 간 최대 거리는 위 이동 거리보다 길 수 있습니다. 맞으면 중앙 조준점이 잠깐 주황색으로 표시됩니다. 체력 피해나 사망은 없습니다.

주먹질은 전신의 상체에 겹쳐 재생하여 이동 중 다리 동작을 유지합니다. 발차기는 오른쪽 다리와 상체에 재생합니다. 1인칭 발차기는 같은 캐릭터에서 분리한 바지·신발을 별도 시야 모델로 보여줍니다. 공격하는 동작 자체는 이동을 잠그지 않습니다. `Editor/MotionPoseAuthor`가 모든 공격 자세의 원본이고 VARCO 기본 모션은 사용하지 않습니다.

현재 타격은 단일 컴퓨터에서 작동합니다. 이후 실제 다인 플레이에는 서버 판정과 상태 동기화를 연결해야 합니다.

## 피격 모션과 타격음

주먹에 맞으면 상대의 방향을 기준으로 앞·뒤·좌·우 피격 모션을 선택합니다. 상체가 충격 방향으로 빠르게 기울었다가 작게 반동을 주고 돌아옵니다. 1인칭 손도 움츠러들고 다시 원래 자세로 돌아옵니다. 직접 만든 `HitFront`, `HitBack`, `HitLeft`, `HitRight`, `Knockback` 클립을 사용합니다.

주먹 피격 시 화면이 맞은 방향으로 기울었다가 약한 반동을 거쳐 0.45초 안에 돌아옵니다. 기본 좌우 기울기는 7도, 앞뒤 기울기는 4도이며 연속 피격도 좌우 10도 / 앞뒤 6도 이내로 제한합니다. 새 피격은 현재 기울기에서 이어지고, 마우스 시점은 계속 조작할 수 있습니다. 화면 효과는 이동 방향이나 입력을 바꾸지 않고, 종료 시 플레이어가 현재 바라보는 시점으로 돌아갑니다. R로 복귀하면 즉시 초기화합니다. 플레이어의 `SourcePlayerController`에서 `Punch Roll Degrees`, `Punch Pitch Degrees`, `Punch Sway Seconds`로 조정할 수 있습니다.

피격은 진행 중인 공격과 예약 공격을 취소합니다. 주먹에 맞아도 즉시 다시 공격할 수 있으며 이동·점프·공중 방향 조작·웅크리기·마우스 시점을 계속 사용할 수 있습니다. 주먹에는 위치를 밀어내는 힘을 추가하지 않습니다. 발차기에 맞을 때만 0.12초의 입력 중단이 적용됩니다.

발차기는 실제 이동 속도에 수평 6m/s와 위쪽 4m/s의 넉백을 더합니다. 지상에서는 바닥 접촉용 하향 속도를 먼저 지워 위쪽 힘이 상쇄되지 않도록 했습니다. 벽에 막히거나 발판에서 떨어질 수 있으며, 기존 이동 속도와 지형에 따라 날아가는 거리가 달라집니다. 각 캐릭터의 `MeleeReceiver`에 있는 `Kick Horizontal Speed`, `Kick Lift Speed`로 조절할 수 있습니다.

명중할 때만 맞은 대상의 위치에서 타격음을 한 번 재생합니다. 주먹 3종과 더 낮고 무거운 발차기 3종을 순환하며 작은 피치 변화를 줍니다. 빗맞거나 벽에 막힌 공격은 대상의 타격음을 재생하지 않습니다.

현재 WAV는 Independent.nu의 [37 hits/punches](https://opengameart.org/node/2558), CC0 공개 타격음을 편집한 두 번째 버전입니다. 기존 합성음의 음높이 하강과 오래 울리는 저음을 제거하고, 타격 시작점을 정렬해 주먹 0.19–0.21초 / 발차기 0.24–0.28초로 다듬었습니다. VARCO Sound 출력물은 사용하지 않았습니다. 원본별 매핑과 출처, 편집 내역은 `Audio/AudioProvenance.txt`에 기록했습니다. `Audio/Punch_*.wav`, `Audio/Kick_*.wav`를 교체한 뒤 `HalliGalli > Prepare Impact Audio`를 실행하면 새 소리를 연결할 수 있습니다.

다인 페널티 카드가 부족한 경우 남은 비공개 카드를 다음 좌석부터 시계 방향으로 지급한 뒤 탈락시킵니다. 탈락자의 공개 카드는 종 획득 전까지 테이블에 남습니다. 2인 최종 라운드 종료 대신 한 명이 모든 카드를 가질 때까지 진행하는 변형을 적용했습니다. 규칙 기준: [AMIGO 공식 설명서](https://blog.amigo-spiele.de/content/ap/rule/01700-DE-AmigoRule.pdf).

밧줄 그랩
Q: 바라보는 방향으로 밧줄을 일직선으로 던집니다. 사거리 12m입니다.
상대에게 걸린 뒤 Q를 다시 누르면 기본적으로 내 쪽으로 강하게 당깁니다. Q로 당기는 순간 마우스를 옆·위로 휘두르고 있으면 그 방향으로 던집니다. 마우스를 멈춘 뒤 누르면 내 쪽으로 당기며, 앞서 돌린 시점이나 작은 조준 움직임은 던질 방향으로 사용하지 않습니다.
당김 속도는 16m/s, 추가 상승 속도는 3.5m/s입니다. 반대 방향의 기존 관성은 이겨내며 횡방향 관성은 유지합니다. 마우스는 현재 프레임의 초당 회전량을 사용해 90도/초 이상일 때 손짓으로 인식합니다. `SourcePlayerController`가 `MeleeCombat`보다 먼저 입력을 읽어 같은 프레임의 방향을 보냅니다.
밧줄은 유도 없이 28m/s로 날아갑니다. 몸 가장자리와 근거리 판정은 넉넉하지만 옆으로 피할 수 있고, 이동 경로를 예측해 맞힐 수도 있습니다. 벽은 관통하지 않습니다.
투척 순간부터 쿨타임 5초이며 횟수 제한이 없습니다. 빗나가도 쿨타임이 적용됩니다.
걸린 상대는 계속 걷고 점프할 수 있습니다. 당기는 순간 기존 관성에 힘을 더하며 충돌과 중력은 그대로 적용됩니다.
밧줄의 피해자에게만 화면 중앙의 빨간 X와 '밧줄에 걸림' 경고가 표시됩니다. 처음에 짧게 커졌다가 연결 중에는 고정되며, 실제 연결 해제·추락·착석 시 사라집니다. 여러 밧줄 중 하나라도 남아 있으면 유지합니다.
벽이 사이를 가로막거나 16m 이상 벌어지면 풀립니다. 주먹·발차기로 전환, 어느 쪽이든 추락·착석하면 연결이 해제됩니다.
추락이나 혼자 다시 앉기로 쿨타임을 초기화할 수 없습니다. 모두 앉아 종 경쟁이 끝나면 초기화됩니다.

화면 안내
플레이 중에는 작은 조준점과 밧줄 아이콘을 표시합니다. 밧줄 테두리는 쿨타임, Q 표시는 사용 키입니다. 마취총은 제거했습니다.
맵과 AI 구성은 대기방에서 변경합니다. 방장은 "+ AI 추가"와 각 AI의 "빼기" 버튼을 사용할 수 있습니다. 사람과 AI를 합쳐 정원까지 최대 6명이며, 방장 혼자 AI를 한 명 추가해도 시작할 수 있습니다. 친구의 자리가 필요하면 AI를 빼면 됩니다.
정원은 상한이며 빈자리를 자동으로 채우지 않습니다. 시작 버튼의 "N명으로 시작"에 표시된 현재 사람+AI 수로 카드 분배와 좌석·출발 위치를 배치합니다.
시작 화면은 카드와 AI를 멈추고 마우스를 해제합니다. 방 정원은 6명으로 고정입니다. 방 만들기는 닉네임, 초대코드로 참가는 닉네임·코드만 입력합니다. 뒤로 또는 Esc로 첫 화면에 돌아옵니다. 일반 에디터 Play와 Windows 실행 모두 같은 시작 화면을 사용합니다. AI와 혼자 하는 대결도 Unity Relay 방을 사용하므로 인터넷 연결이 필요합니다.
AI는 방장 PC에서만 카드 판단·이동·공격을 실행하며 다른 참가자는 그 결과를 받습니다. 로딩 완료는 사람에게만 확인하고, AI는 자동 준비됩니다. 대결 중 AI 추가·제거는 차단하며 대기방에 돌아온 뒤 편집합니다. 검증 결과는 `TestResults/room-bots-validation.json`과 `TestResults/room-bots-network-validation.json`에 기록합니다.
카드 화면은 차례와 필요한 조작만 표시합니다. 과일 합계나 기립 정답은 알려주지 않습니다.
최종 승자가 정해지면 기존 HUD와 같은 금색·차콜의 둥근 배너에 **승자**와 승자의 실제 닉네임을 5초간 표시합니다. 긴 한글 닉네임도 패널 안에 맞추며, 모든 참가자에게 같은 승자와 `N초 후 대기방으로` 안내를 보여 줍니다. 방장이 정한 하나의 복귀 시각을 공유하며, 메뉴를 열어도 시간이 지나면 모두 자동으로 대기방으로 돌아갑니다. 기존 방·초대코드·맵·사람·AI는 유지하고 사람만 다시 준비합니다. R은 결과 화면을 건너뛰지 않으며 다음 대결에는 이전 타이머가 남지 않습니다. 대기방이 없는 로컬 에디터 테스트에서는 R로 새 대결을 시작합니다. 화면 검증은 `TestResults/victory-validation.json`, 두 클라이언트의 승자·자동 복귀 검증은 `TestResults/victory-network-validation.json`에 기록합니다. 친구도 같은 최신 빌드를 사용해야 합니다.


연습실
시작 화면의 연습실은 인터넷 없이 열립니다. 카드와 종 경쟁 없이 가만히 서 있는 AI 5명을 상대로 좌클릭 주먹, F 발차기, Q 밧줄을 연습합니다. 밀려난 상대는 잠시 뒤 제자리로 돌아옵니다. R은 내 위치를 출발점으로 되돌리고 밧줄 쿨타임을 충전하지 않습니다. Esc → 시작 화면으로 나갑니다.


폐공장 기계실 (추가 맵)
방의 맵 목록에서 "폐공장"을 선택합니다. 기존 VARCO 실내 자산을 활용한 공장 코스입니다.
옆으로 밀어내는 컨베이어 → 왕복 발판 → 역방향 컨베이어와 교대 압착기 → 중간 체크포인트 → 높아지는 발판과 두 번째 왕복 발판 → 종으로 이어집니다.
경고등이 청록색이면 열림, 주황색이면 압착 예고, 빨간색이면 작동 중입니다. 압착기 양옆의 좁은 가장자리로 통과할 수도 있습니다.
프레스가 내려와 몸에 닿으면 즉시 추락 처리합니다. 앉은 상태도 동일합니다. 압착되거나 떨어지면 중간 체크포인트로 복귀하며, 체크포인트에 도착하기 전에는 출발점으로 돌아갑니다. R로도 같은 복귀를 사용할 수 있습니다.
최대 6인과 AI를 지원하며 출발선·첫 발판 간격은 모든 자리에서 동일합니다. 온라인 기계 동작은 공통 시각을 따르고 피격·종 판정은 방장이 처리합니다.
새 맵이 포함된 같은 빌드를 친구들도 사용해야 합니다.


첫걸음 — 엇박 왕복 발판
중간 대기 발판에 체크포인트가 있습니다. 두 운반 발판은 각각 5.6m를 반대 박자로 왕복합니다. 첫 발판에 올라 기다린 뒤 두 발판이 가까워지는 순간 두 번째로 갈아타고, 도착 발판과 가까워지면 종으로 향합니다.
운반 발판은 여러 명이 함께 탈 수 있는 폭이고 난간이 없어 발차기와 밧줄로 서로 밀어낼 수 있습니다. 출발 시점과 관계없이 계속 왕복해 뒤쪽 플레이어가 기다리는 선두를 따라잡을 기회를 만듭니다.
떨어지거나 R을 누르면 저장된 대기 발판으로 돌아오며 운반 발판의 왕복 주기는 초기화되지 않습니다.
