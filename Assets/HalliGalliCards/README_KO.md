# 기본판 과일 카드 56장

원작 기본판의 과일 종류와 장수 분포를 적용한 Unity 카드 에셋입니다. 딸기, 바나나, 라임, 자두가 각각 14장씩 있습니다.

| 카드에 그려진 과일 수 | 과일 한 종류당 장수 | 네 종류 합계 |
| --- | ---: | ---: |
| 1개 | 5장 | 20장 |
| 2개 | 3장 | 12장 |
| 3개 | 3장 | 12장 |
| 4개 | 2장 | 8장 |
| 5개 | 1장 | 4장 |
| 합계 | 14장 | 56장 |

앞면은 4종 × 5단계 = 20가지이며, 덱에 같은 앞면이 정해진 수량만큼 들어갑니다. 각 카드에는 한 종류의 과일만 있습니다. 앞면에는 개수를 알려주는 숫자나 정답 표시가 없고, 56장 모두 동일한 뒷면을 사용합니다. 그림과 뒷면은 직접 제작한 벡터 일러스트입니다. 원작 그림이나 로고를 스캔한 에셋이 아닙니다.

## 구성

- `Data/Classic56.asset`: 20개 카드 정의와 덱 구성, 공통 뒷면, 프리팹 연결.
- `Data/*.asset`: 과일 종류, 과일 수, 덱에 포함되는 장수, 앞면 텍스처와 머티리얼.
- `Art/*.png`: 앞면 20종과 공통 뒷면 1종. 1120×1740 픽셀.
- `Art/VectorSource/*.svg`: 수정 가능한 카드 및 과일 벡터 원본.
- `Prefabs/FruitCard.prefab`: 앞·뒤·측면을 나눈 둥근 모서리의 3D 카드.
- `Demo/CardGallery.unity`: 20가지 앞면을 한눈에 확인하는 씬.
- `classic-deck.json`: Unity 밖에서도 읽을 수 있는 수량 데이터.

카드의 가로:세로는 56:87입니다. 1인칭에서 보기 쉽도록 월드 크기는 가로 0.48m로 확대했습니다. 실제 종이 카드 크기를 표현할 때는 프리팹 전체를 축소하세요.

## 사용

```csharp
// deck에는 Classic56.asset을 연결합니다.
var cards = deck.CreateShuffled(seed: 1234); // 고유 Serial을 가진 56장
var hands = deck.Deal(playerCount: 4, seed: 1234); // 각 14장
view.SetCard(deck.Find(FruitKind.Plum, 3));
view.SetFaceDown(true); // 공통 뒷면
view.SetFaceDown(false, animate: true); // 테이블을 관통하지 않도록 들어서 뒤집기
```

분배는 한 장씩 돌아가며 56장을 모두 나눕니다. 기본 시작 좌석 기준 2인 28/28장, 3인 19/19/18장, 4인 14장씩, 5인 12/11/11/11/11장, 6인 10/10/9/9/9/9장입니다. `firstSeat`로 첫 수령 좌석을 바꿀 수 있습니다. 난수 시드가 같으면 같은 순서로 재현됩니다. `FruitCardDefinition`은 공유되는 카드 종류 데이터이고 `FruitCardInstance`는 실제 한 장의 식별자입니다.

## 현재 프로젝트 연결 범위

BellRunCourse는 56장을 섞어 선택한 2~6인에게 모두 나누고 뒷면으로 시작합니다. 공개 더미는 원형으로 배치하고 번호와 색상으로 좌석을 구분합니다. 각 참가자는 자기 차례에 한 장을 공개합니다. 사람은 좌클릭, 로컬 AI는 지연 후 공개합니다. 카드의 고유 ID에 따라 실제 공개·비공개 더미의 위치와 앞뒷면을 갱신합니다.

`HalliGalliMatch`는 2~6인 차례와 카드 소유권을 관리합니다. 첫 기립에서 공개를 동결하고, 각 공개 더미 맨 위의 같은 과일 합이 정확히 5인지 판정합니다. 틀리면 다른 생존 참가자에게 한 장씩 지급하고 재착석 의무가 생깁니다. 모두 앉기 전에는 공개할 수 없습니다. 정상 기립 후 종 획득자는 모든 공개 카드를 자기 비공개 덱 아래에 넣으며 다음 턴을 시작합니다. 마지막 공개 직후에는 탈락하지 않고, 공개 더미도 잃거나 지급할 페널티 카드가 부족할 때 탈락합니다. 2인도 한 명이 모든 카드를 가질 때까지 진행합니다. 판정 정답을 미리 표시하지 않습니다.

`CourseCardGame`과 `CourseSession`이 이 모델을 이동·좌석·종에 연결합니다. 카드 공개 시 책상 위 카메라로 전환하며, 정상적으로 종을 울리면 모두 자기 자리에 즉시 앉고 획득자부터 다음 카드를 공개합니다. 잘못 기립했을 때는 직접 다시 앉아야 합니다. 현재 씬은 나 1명 + AI 1~5명의 로컬 2~6인 대결이며 Esc 메뉴에서 인원을 선택합니다. 네트워크 다인 플레이는 아직 없습니다. 검사 결과는 `TestResults/match-validation.json`에 있습니다. 페널티 카드 부족 시 남은 카드만 시계 방향으로 지급하고 탈락시키는 처리를 사용합니다.

`HalliGalliClassicCards.unitypackage`는 다른 프로젝트에서도 사용할 수 있도록 카드 런타임과 에셋만 포함합니다. 전체 프로젝트의 제작용 Editor 스크립트는 코스 프로젝트 안에 남아 있습니다.

## 구성 확인 출처

- [AMIGO 공식 설명서](https://blog.amigo-spiele.de/content/ap/rule/01700-ES-AmigoRule.pdf): 56장, 2~6인, 모든 카드를 한 장씩 나누는 준비 방법. PDF 5~7쪽에 영문 설명이 있습니다.
- [실물 구성과 상세 수량](https://www.brettspiele-report.de/halli-galli/): 과일별 1~5개 카드의 수량 5/3/3/2/1 확인.
- [PaperGames 공식 제품 정보](https://papergames.com.br/halli-galli/): 과일 4종, 카드당 1~5개, 카드 56장 및 56×87mm 규격.

그림 수량, 덱 분포, 고유 카드 ID, 섞기, 2~6인 분배, 카드 앞뒷면과 테이블 배치를 `TestResults/cards-validation.json`에서 검증합니다.
