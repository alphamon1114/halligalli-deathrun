할리갈리런 — 오프라인 전시 데모
제작자: 조건희
기반 버전: 1.0.10

실행 방법
1. ZIP을 완전히 압축 해제합니다.
2. 01_HALLIGALLI_RUN_Offline 안의 HalliGalliRunDemo.exe를 실행합니다.
3. 참가 인원(나 1명 + AI 1~5명)과 공식 맵을 선택하고 'AI 대결 시작'을 누릅니다.
인터넷 연결, 로그인, GitHub 최신 버전 확인, BellRunLauncher가 필요하지 않습니다.
EXE만 따로 옮기지 말고 Data 폴더와 DLL을 포함한 폴더 전체를 옮기세요.

GstarLauncher에 등록
- Games 폴더 안에 01_HALLIGALLI_RUN_Offline을 넣습니다.
- setting에서는 개별 게임 폴더가 아닌 상위 Games 폴더를 선택합니다.
- 목록 새로고침 후 할리갈리런 — 오프라인 데모를 선택하고 PLAY를 누릅니다.
- config의 텍스트 6개와 썸네일·이미지 3장은 미리 준비되어 있습니다.

시연 흐름
- 같은 과일이 정확히 5개일 때 자리에서 일어나 장애물을 넘어 종을 먼저 누릅니다.
- 카드 공개: 좌클릭 / 일어나기·앉기·종: E / 이동: WASD / 점프: Space.
- 달리는 중 좌클릭 밀치기 / F 발차기 / Q 밧줄 / R 복귀 / C 아이템 사용.
- 처음에는 '전투 / 서프 연습'을 사용하세요. 조작키와 마우스 감도는 게임 안에서 변경할 수 있습니다.
- Esc 메뉴에서 다시하기·맵/인원 선택·데모 홈으로 이동할 수 있습니다. 메뉴를 열어도 AI 대결은 계속 진행됩니다.
- 승패 화면에서 다시 대결하거나 홈으로 돌아갈 수 있습니다. 다음 관람객은 홈에서 새 경기를 시작하세요.
- 연습실·캐릭터 꾸미기·로컬 맵 만들기도 인터넷 없이 사용할 수 있습니다.
- 온라인 방 만들기·초대코드 참가·다른 PC와의 멀티플레이는 이 데모에 없습니다.

공개판과의 구분
- 데모는 독립 빌드이며 공개판의 최신 버전 제한을 바꾸지 않습니다.
- 추후 공개판이 업데이트되어도 이 데모는 실행됩니다. 데모 자체의 업데이트는 폴더 전체를 교체합니다.
- 데모 저장 위치: %USERPROFILE%\AppData\LocalLow\HalliGalli Prototype\HalliGalli Run Offline Demo
  공개판의 설정·사용자 맵과 분리되어 있습니다.
- 이 ZIP은 전시용입니다. 일반 업데이트 런처의 배포 파일로 게시하지 마세요.
