할리갈리 데스런 — BELL RUN 카드 대결
Unity 버전: 6000.6.0f1

시작 방법
1. Unity Hub에 HalliGalliDeathrun 폴더를 추가합니다.
2. Assets/HalliGalliMovement/Demo/BellRunCourse.unity를 엽니다.
3. Play를 누르면 시작 화면이 열립니다. 방 만들기 / 초대코드로 참가 / 연습실 / 맵 만들기 중 하나를 고릅니다.
Windows 버전은 압축을 풀고 HalliGalliMovement.exe를 실행합니다.
혼자 하고 싶으면 방을 만든 뒤 "+ AI 추가"를 눌러 상대를 한 명씩 추가합니다. 방장 1명 + AI 1명부터 시작할 수 있습니다.
정원은 항상 6명이며 친구와 AI를 합해 계산합니다. 방장은 AI 옆 "빼기"로 빈자리를 만들 수 있으며, 게임 중에는 구성을 변경할 수 없습니다. 내 차례에 좌클릭으로 카드를 공개합니다.
정원은 6명으로 고정입니다. 시작 시 현재 방에 있는 사람과 AI만으로 카드와 자리를 배치하며, 빈자리를 자동으로 채우지 않습니다. 예: 정원 6명에 사람 2명 + AI 1명이면 "3명으로 시작"합니다.
티셔츠 색은 홈/입장 화면과 대기방의 색 동그라미에서 고릅니다. 파랑·빨강·주황·노랑·초록·하늘·보라·분홍 8가지이며 선택은 저장됩니다. 같은 방에서 이미 쓰는 색은 선택할 수 없고, 입장 시 겹치면 빈 색으로 자동 배정합니다. 자동 배정은 저장한 선호색을 바꾸지 않습니다.

내 맵 제작과 파일 전달
1. 시작 화면 → 맵 만들기 → 아래 큰 부품 슬롯(1~6)에서 고르세요. 나머지는 ‘모든 부품’에 있습니다. 짓기에서 미리보기를 보고 클릭해 블록 옆에 붙이거나 위에 쌓습니다. 작게/보통/크게, R 90도 회전, 지우개, 실행 취소로 편집합니다. 선택 → 옮기기 / 색·장치에서 방향 버튼과 색을 고르며, 이동 발판은 방향·거리·빠르기 버튼으로 설정합니다.
2. 기본은 1인칭 제작입니다. Tab 또는 맵 클릭으로 조작, Tab/Esc로 메뉴용 마우스를 풉니다. WASD+마우스로 이동·둘러보기, 비행 중 Space/Ctrl로 위아래 이동합니다. V로 노클립 비행/실제 걷기·점프를 전환하고, 걷기에서는 Space로 점프해 간격을 확인하세요. 벽 안에서는 걷기로 바꿀 수 없습니다. Q로 붙여 놓기/공중에 놓기 전환, 공중 배치는 휠로 거리 조절, 좌클릭 설치, 우클릭 선택·설정, Delete 조준 부품 삭제입니다. 점선과 높이 표시를 보고 놓으세요. 전체 보기에서는 우클릭 회전·가운데 드래그 이동을 사용합니다. Ctrl+D 복제, Ctrl+Z/Y 실행 취소/다시 실행. 제작 중 걷기·점프는 저장용 클리어 인증이 아닙니다.
3. F8 클리어 검증에서 혼자 출발점부터 도착 종까지 이동하여 E로 종을 울리세요. 낙하/R은 체크포인트 없이 처음부터 재도전합니다. 성공 후 F8로 편집에 돌아와 Ctrl+S 또는 저장 버튼으로 저장합니다. 수정하면 다시 검증해야 합니다.
4. 클리어한 맵은 파일 → 내보내기에서 .bellmap 파일 하나를 친구에게 보내세요. 가져온 원본은 ‘받은 맵’에 보관되어 재클리어 없이 방에서 선택할 수 있습니다. 함께 열리는 편집 사본은 미검증 초안이며 수정본 저장·공유에는 직접 클리어가 필요합니다.
5. 홈 → 방 만들기 → 사용자 맵에서 내 맵 또는 받은 맵을 선택합니다. 참가자는 자동 다운로드·파일 검사 후 준비합니다. 받은 맵은 게임을 꺼도 보관되며 나중에 그 맵으로 방을 만들 수 있습니다. 같은 내용의 맵이 있으면 다시 다운로드하지 않습니다.
아이템 박스: 아래 5번 슬롯에서 선택하고 바닥에 놓으세요. 크기는 고정이며 위치·수평 회전·색을 변경합니다. 닿으면 아이템 획득, C로 사용, 8초 뒤 재등장합니다. 공식 레이스와 같이 순위에 관계없이 미사일·바나나·바리게이트를 각각 1/3 확률로 얻습니다. 사용자 맵의 순위 표시는 종까지의 직선거리 기준입니다. F8 검증에서도 사용 가능하고 .bellmap 파일과 방 자동 다운로드에 포함됩니다.
최대 512개 부품/512KiB, 도착 종은 하나입니다. 외부 코드나 모델은 포함하지 않습니다. 모든 참가자는 프로토콜 35의 같은 최신 빌드를 사용해야 합니다.

친구와 온라인 대결
1. 시작 화면에서 "방 만들기"를 누릅니다.
2. 닉네임을 입력하고 "방 만들기"를 누릅니다.
3. 초대 코드 옆 "복사"로 코드를 친구에게 전달합니다. 친구는 같은 최신 Windows 빌드를 실행하고 "초대코드로 참가"에서 닉네임과 코드를 입력합니다.
4. 필요하면 "+ AI 추가"로 봇을 한 명씩 넣습니다. 방장이 공식 맵 또는 사용자 맵을 고른 뒤 사람 참가자가 준비 완료를 누르면 시작할 수 있습니다. 맵을 바꾸면 사람은 다시 준비해야 합니다. AI는 자동으로 준비되며, 카드도 사람과 동일하게 분배받습니다.
5. 게임 중 Esc로 방 메뉴를 열 수 있습니다. 방장만 대기방 복귀와 다음 맵 시작을 결정합니다. 온라인에서도 R은 자신만 체크포인트로 복귀시킵니다. 대결이 끝나면 승자 화면을 5초간 보여준 뒤 모두 자동으로 대기방에 돌아갑니다.
6. 방장이 나가면 방이 종료됩니다. 진행 중 참가자가 나가면 남은 사람은 대기방으로 돌아가 새 게임을 시작합니다.
게임이 진행 중인 방에는 새로 입장할 수 없습니다. 정원 초과·잘못된 코드·연결 종료는 화면에 표시합니다.
Unity Lobby + Relay를 사용하므로 친구가 포트포워딩이나 별도 서버 설치를 할 필요는 없습니다.
방장 PC가 카드·이동·근접 공격·밧줄·종 판정을 맡습니다. 참가자의 이동은 즉시 예측하고 서버 결과에 맞춰 보정합니다.
서버가 보내는 카드 정보는 비공개 뭉치의 장수와 이미 공개된 앞면뿐이며, 남은 카드 순서와 섞기 시드는 보내지 않습니다.
프로젝트는 Unity Cloud "HalliGalli Deathrun - Bell Run"에 연결되어 있습니다. 다른 Cloud 프로젝트로 바꾸려면 Project Settings → Services를 사용합니다.
Unity 에디터와 Windows 빌드는 각각 다른 익명 로그인 프로필을 사용하므로 같은 PC에서도 두 창으로 테스트할 수 있습니다.
이번 작업에서는 결제 설정을 변경하지 않았습니다. Relay 무료 구간은 월평균 CCU 50명, 통신량은 CCU당 3GiB(월 최대 150GiB)이며 별도 서비스 한도가 적용됩니다.
무료 한도를 넘으면 결제 정보가 없는 프로젝트는 서비스가 제한될 수 있습니다. 최신 정책: https://unity.com/products/gaming-services/pricing
네트워크 재현 검증 결과: TestResults/network-validation.json
unitypackage만 다른 프로젝트에 가져올 때는 Package Manager에서 com.unity.netcode.gameobjects 2.13.3과 com.unity.services.multiplayer 2.4.1도 설치해야 합니다.

맵 선택
대기방의 공식 맵 / 사용자 맵에서 방장이 코스를 고릅니다. 사용자 맵은 자동 전송·검증이 끝나야 준비할 수 있습니다. 게임 중에는 Esc → 대기방으로 돌아온 뒤 다음 맵을 선택합니다.
아이템 레이스: 마지막 공식 맵. 220m 연속 트랙과 32개 아이템 박스. 순위와 무관하게 미사일·바나나·바리게이트를 각각 1/3 확률로 획득합니다. 하나씩 보관하고 C로 사용합니다. 미사일은 바라보는 방향의 상대를 락온하므로 선두도 뒤돌아 추격자에게 쏠 수 있습니다. 명중하면 기존 속도를 지우고 약 3.3m 띄우며 1.4초간 수평 이동을 막습니다. 몸만 공중제비를 돌고 카메라는 뒤집히지 않습니다. 바나나는 뒤쪽 1.15m에 설치해 미끄러뜨립니다. 바리게이트는 시선 뒤 3m에 설치되며 현지 길 너비 약 1/3·높이 2.2m·두께 .6m로 8초간 막습니다. 점프·낙하 중에도 두 설치 아이템은 뒤쪽 거리를 유지한 채 그 위치 아래의 실제 바닥에 즉시 놓입니다. 아래 바닥이 없거나 설치 면·공간이 안전하지 않으면 아이템은 유지됩니다. 바리게이트 양옆 우회가 가능합니다. 레이저·실드·공은 제거했습니다. 박스는 8초 후 재등장하며 착석·복귀·라운드 종료 시 아이템과 효과가 해제됩니다. 카드·종 규칙은 그대로이며 C는 조작키 설정에서 변경합니다.
왕의 회랑: 3단계. 25개 양면 삼각 서프·5개 방·체크포인트 4곳. 서프 길이를 644→450m(69.9%)로 줄였고 틈·착지대 연결을 포함한 진행 거리는 약 619m입니다. 내리막 가속면과 처음부터 끝까지 올라가는 도약대를 분리해 가운데 골을 없앴습니다. 2.2~3.2m 틈, 0.65~0.75m 높은 착지와 1.2~1.6m 낮은 착지가 섞입니다. 20×20m 체크포인트에 착지한 뒤 화살표를 따라 90도씩 네 번 방향을 바꾸세요. 한쪽 면을 골라 진행할 수 있고 25개 구간을 순서대로 통과해야 종을 울립니다. 서프 도약은 곡면이 만든 상승 속도와 공중 조향을 사용하며 낙하나 R은 마지막 체크포인트로 복귀합니다.
기존 VARCO 석문·연꽃 기둥·아누비스·벽화·석관·화로를 재사용했습니다. 장식은 벽 쪽으로 옮기고 충돌을 제거했으며, 실제 외벽·낙하 구역·발판은 충돌을 유지합니다. 다른 맵과 이동 물리는 바꾸지 않았습니다. 맵 파일: Assets/HalliGalliMovement/Demo/PyramidSurfCourse.unity
첫걸음: 입문 / 1단계. 낡은 건물 안에서 철제 발판을 밟는 짧은 기본 점프맵입니다.
정상 쟁탈은 짧은 등반 경쟁 코스이며, 서프 수로는 11개 편측 활주 구간으로 확장했습니다. 이동 숙련도와 방해에 따라 실제 도착 시간은 달라집니다.
정상 쟁탈: 어려움 / 3단계. 하나의 봉우리를 한 바퀴 돌아 올라가는 공통 코스입니다.
얕은 착지점, 좁은 바위턱, 높이가 다른 대각선 점프가 번갈아 나옵니다. 발판 크기·방향·간격이 일정하지 않으므로 착지 후 다음 발판을 확인하세요.
중간 두 곳의 좁은 숏컷 발판은 바위 안쪽 모서리를 질러 세 번의 점프를 두 번으로 줄이고 본길에 합류합니다.
넓은 입구·체크포인트·쉼터에서는 상대 옆으로 추월할 수 있습니다. 노출된 바위턱에서 점프를 놓치거나 바깥으로 밀리면 추락합니다. AI도 앞을 막는 상대가 있으면 숏컷을 시도합니다.
등산맵도 출발선과 첫 발판은 여섯 자리에서 동일하고, 종을 누르면 모두 즉시 착석합니다.
각 코스 중간의 청록색 CHECK 발판에 착지하면 이번 종 경쟁의 복귀 지점이 저장됩니다. 등산맵은 봉우리 뒤쪽의 공통 발판에 하나 있습니다.
추락하면 잠깐 대기한 뒤 저장한 체크포인트에서 속도 없이 다시 출발합니다. 저장 전에는 출발점으로 돌아갑니다. 밀치기와 발차기로 서로 방해할 수 있습니다.
서프 수로: 어려움 / 4단계. 직진 → 낙하 → 직접 180도 회전 → 역방향 활주 → 오른쪽 곡면 도약 → 연속 커브 → 반대편 뱅크로 전환 → 왼쪽 곡면과 공중 연결 → 종 발판 착지 순서입니다.
첫 두 발판을 건넌 뒤 하나의 왼쪽 경사면으로 합류합니다. 커브도 마주 보는 벽 없이 한쪽 면만 사용합니다.
진행 방향을 바라볼 때 왼쪽 면에서는 A, 오른쪽 면에서는 D를 눌러 면 쪽으로 조향합니다.
진입 후 W를 놓고 마우스를 부드럽게 돌려 속도를 이어가세요. 틈에서는 공중 조향으로 다음 면을 받습니다.
경사면은 서 있는 지면이 아니므로 Space를 눌러도 추가 점프가 나오지 않습니다. 평평한 발판에서는 기존 점프가 가능합니다.
도약 직전의 곡면은 위로 휘어 올라갑니다. 진입 속도로 실제 도약하며, 속도가 부족하면 떨어진 종 발판에 닿지 않습니다. 회전의 안쪽·바깥쪽 선택과 낙하 착지에 따라 앞뒤 순서가 바뀔 수 있습니다.
통과한 경사면은 화면 하단의 작은 점으로 표시됩니다. 보라색 끝선 11개를 순서대로 통과해야 종을 누를 수 있습니다.
서프 체크포인트는 180도 회전 착지장, 첫 곡면 도약 뒤 중간 착지장, 반대편 뱅크로 바꾸는 착지장까지 세 곳입니다. 해당 구간을 통과하고 실제로 착지해야 저장됩니다.
첫 직선 아래의 가로 칸막이는 감전 위험 구역입니다. 노랑·검정 경계선과 번개 경고 문양, 표면에서 튀는 푸른 전기로 구분합니다. 몸이 닿으면 마지막 체크포인트로 복귀하며, 체크포인트를 저장하기 전에는 출발점으로 돌아갑니다. 위쪽 활주면 끝의 열린 공간으로 내려가 회전하세요.
출발 구역의 양옆·뒤는 격벽으로 막고 감전 구역을 출발대 아래까지 넓혔습니다. 바로 아래 두 번째 활주면으로 뛰어내릴 수 없으며 첫 활주면 끝의 열린 공간으로 내려가야 합니다.
초반과 후반 구역 사이에는 바닥부터 천장까지 격벽이 있습니다. 외곽 커브가 통과하는 개구부로 진행하며, 초반에서 종 쪽으로 바로 날아가 구간을 건너뛰는 길을 막습니다. 격벽은 몸을 막는 벽이고, 푸른 전기가 흐르는 가로 칸막이는 접촉 시 복귀하는 위험 구역입니다.
서프 체크포인트 복귀 시 저장된 구간(첫 번째·세 번째·일곱 번째)까지 인정하며 남은 구간은 다시 통과해야 합니다. 복귀할 때는 다음 경사면 방향을 바라봅니다.
정밀 점프는 제작 예정으로 표시되며 아직 선택할 수 없습니다.
Unity에서 등산맵을 바로 열려면 Assets/HalliGalliMovement/Demo/ClimbCourse.unity를 사용합니다.
서프맵은 Assets/HalliGalliMovement/Demo/SurfCourse.unity입니다.

조작
시작 화면·대기방·Esc 메뉴 → 조작키 설정에서 키보드, 마우스 버튼, 휠을 지정할 수 있습니다.
동작마다 최대 세 개를 함께 지정하며 변경 즉시 이 PC에 저장됩니다. 중복 키는 서로 바꿀지 선택하고 ×로 해제합니다. 기본값 복원도 가능합니다.
아래는 기본 조작입니다. 화면의 동작 안내도 지정한 키를 따라 바뀝니다. Esc와 메뉴 클릭은 고정입니다.
WASD 이동 / 마우스 시점 / Space 또는 휠 아래 점프 / Ctrl 웅크리기
휠 양방향 점프 버튼으로 휠 위도 추가할 수 있습니다. 휠은 한 번씩 점프 입력만 보내며 자동 연속 점프를 켜지 않습니다.
기본 이동 속도는 4.5m/s입니다. Shift에는 이동 기능이 없습니다. Ctrl 웅크리기와 공중 조향·관성은 유지됩니다.
등산맵의 높은 턱에서는 점프한 뒤 공중에서 Ctrl을 눌러 다리를 접어 착지합니다.
서서 이동할 때 좌클릭: 왼손 → 오른손 번갈아 빠른 밀치기 / F: 오른발 발차기
마우스 좌클릭: 모두 앉아 있고 내 차례일 때 카드 한 장 공개
E: 일어나기, 종 앞에서 종 울리기, 자기 자리 근처에서 앉기
R: 최근 체크포인트로 복귀 (없으면 출발점, 경기 종료 후에는 새 게임) / Esc: 커서 해제 / 화면 클릭: 조작 재개
V: 전신 확인 시점 (디버그)

코스
테이블 → 일렬 좌석과 공통 출발선 → 좌석별 첫 발판 → 합류 → 좁은 발판 → 지그재그 점프 → 종
좌석 간격은 1.5m이며, 모두 같은 Z 위치에서 정면으로 출발합니다.
출발점부터 첫 발판 중심까지 수평 3m, 점프할 빈틈 1.3m, 첫 발판 높이 0.15m로 동일합니다.
첫 발판은 각 좌석 정면에 있으며 폭 1.3m, 길이 2m입니다. 테이블은 의자 뒤쪽에 두어 출발 동선을 막지 않습니다.
합류 뒤에는 공용 코스에서 서로 밀치고 방해합니다. 전체 종까지 이동 거리가 모든 자리에서 같다는 의미는 아닙니다.
로컬 AI 1~5명이 자기 차례에 공개하고 종을 향해 달립니다. AI끼리도 가까운 대상을 공격합니다.
발판에는 난간이 없습니다. 밀치기로 상대를 떨어뜨릴 수 있습니다.
추락 판정 후 0.7초 대기하고 체크포인트 또는 코스 입구에서 다시 출발합니다. 복귀 시 기존 속도는 사라집니다.
체크포인트는 개인별로 저장되며 종을 누르거나 다시 앉거나 새 대결을 시작하면 초기화됩니다. 화면에 '복귀 지점 저장됨'으로 표시됩니다.
잘못 기립한 경우에는 체크포인트를 저장할 수 없으며 의자 옆에서 재시작합니다.
정상적으로 종을 울리면 공개 카드를 획득하고 모두 자기 자리에 즉시 앉습니다.
다시 뛰어오는 구간 없이 다음 공개 턴으로 넘어갑니다. 추락 중인 참가자도 바로 착석합니다.

카드 진행
56장을 섞어 모두 나눕니다. 2인 28장씩 / 3인 19·19·18장 / 4인 14장씩 / 5인 12·11·11·11·11장 / 6인 10·10·9·9·9·9장입니다.
처음에는 모두 뒷면이며 1번 자리(온라인에서는 방장)가 먼저 공개합니다. 좌석 번호 순으로 차례가 돌아갑니다.
테이블 안쪽의 화살표가 카드 공개 순서를 가리킵니다. 금색 화살표와 테두리는 지금 카드를 낼 사람을 표시합니다.
카드 공개가 중지되면 금색 강조가 꺼집니다. 덱이 빈 사람과 탈락한 사람은 화살표 순서에서도 건너뜁니다.
공개 더미는 원형, 비공개 더미는 그 바깥에 배치합니다. 번호와 색상으로 카드·출발 레인을 대응시킵니다. 의자는 모두 같은 외형입니다.
나와 상대의 남은 카드는 뒷면 카드뭉치의 두께로 가늠할 수 있습니다. 카드를 내면 얇아지고, 카드를 얻으면 두꺼워집니다.
내 차례에 좌클릭하면 한 장을 자기 공개 더미 위에 놓고 상대 차례가 됩니다.
누구든 카드를 공개하면 0.22초 동안 책상 위를 내려다보는 시점으로 전환합니다. 살짝 기울인 시점으로 카드 옆면의 두께도 볼 수 있습니다.
참가자들의 공개 카드가 모두 보이는 시점을 유지하고, E로 일어나면 즉시 이동용 1인칭으로 돌아옵니다.
책상 시점에서는 손이 카드를 가리지 않도록 손 카메라를 숨기고 마우스 시점 회전을 잠시 고정합니다.
대결에 추가한 AI는 약 1.2초 뒤 자기 카드를 공개합니다. 온라인 참가자는 자기 차례에 직접 좌클릭합니다. 각 공개 더미의 맨 위 카드만 계산합니다.
같은 과일이 정확히 5개인지 직접 판단하세요. 화면에 정답 알림은 없습니다.
E로 일어나면 즉시 모든 카드 공개가 멈춥니다. 다른 참가자도 일어나 경쟁할 수 있습니다.
잘못 일어나면 다른 생존 참가자마다 카드 한 장을 지급합니다. 자동으로 앉혀 주지 않습니다.
자기 자리에서 E로 다시 앉아야 합니다. 추락하거나 종에 도착해도 페널티는 없어지지 않습니다.
정상 기립 후 종을 먼저 울리면 모든 공개 더미를 자기 비공개 덱 아래로 가져옵니다.
종을 울리면 자동 착석한 뒤 종을 울린 사람이 다음 카드를 공개합니다.
1대1은 비공개 카드가 0장이 되는 즉시 패배합니다. 마지막 카드를 공개해 5개가 되어도 게임이 끝납니다. 기립 페널티로 마지막 카드를 내어도 같습니다.
3인 이상으로 시작한 대결에서는 마지막 비공개 카드를 공개한 사람도 공개 더미를 잃기 전까지 종 경쟁에 참여할 수 있습니다.
상대가 모두 탈락하여 한 명만 남아 카드를 모두 가지면 최종 승리입니다.
최종 승리 시 화면 중앙에 금색 "승자" 배너와 승자의 닉네임을 5초간 표시합니다. 모든 참가자에게 "N초 후 대기방으로"를 안내하고, 시간이 끝나면 같은 방·초대코드·맵·참가자·AI를 유지한 채 함께 대기방으로 돌아갑니다. R을 누를 필요가 없으며, 다음 대결은 사람이 다시 준비한 뒤 방장이 시작합니다.
기립과 공개를 동시에 누르면 기립을 우선하여, 판단 당시 카드가 바뀌지 않습니다.

밀치기와 발차기
좌클릭은 한 손으로 빠르게 밀고(수평 추가 속도 4.5m/s), F는 준비 동작 후 오른발로 찹니다(22.5m/s). 기존 발차기의 절반을 좌클릭에, 2.5배를 F에 적용했습니다.
빠른 밀치기는 0.55초, 발차기는 1.1초 뒤 다음 동작으로 돌아옵니다.
F는 사용 시작부터 2초 쿨타임입니다. 동작이 끝나면 쿨타임 중에도 좌클릭으로 밀 수 있습니다. 연타나 R 복귀로 쿨타임을 없앨 수 없습니다.
플레이 중 오른쪽 아래에 좌클릭 밀치기·F 발차기·Q 밧줄 안내가 표시됩니다. F와 Q는 남은 시간과 원형 게이지를 보여주며 변경한 조작키도 반영합니다.
위로 띄우거나 시야를 가리지 않으며 맞은 직후에도 이동·점프·반격·마우스 시점 조작이 가능합니다.
2026-11-02 평지에서 정지한 상대의 검증 이동량은 좌클릭 약 0.42m, 발차기 약 2.72m입니다. 이동 속도·지형에 따라 달라지고 발판 가장자리에서는 떨어질 수 있습니다.
맞은 뒤 0.65초간 추가 밀치기를 무시합니다. 연타로 보호 시간이 늘어나지 않으며 보호 중에도 반격할 수 있습니다.
공격 키를 누르고 있어도 자동으로 반복하지 않습니다.
좌석에 앉아 있거나 추락 후 복귀 중인 참가자는 공격을 실행하거나 받지 않습니다.

밧줄 그랩
Q: 바라보는 방향으로 밧줄을 일직선으로 던집니다. 사거리 12m입니다.
상대에게 걸린 뒤 Q를 다시 누르면 기본적으로 내 쪽으로 강하게 당깁니다. Q로 당기는 순간 마우스를 옆·위로 휘두르고 있으면 그 방향으로 던집니다. 마우스를 멈춘 뒤 누르면 내 쪽으로 당기며, 앞서 돌린 시점이나 작은 조준 움직임은 던질 방향으로 사용하지 않습니다.
밧줄은 유도 없이 28m/s로 날아갑니다. 몸 가장자리와 근거리 판정은 넉넉하지만 옆으로 피할 수 있고, 이동 경로를 예측해 맞힐 수도 있습니다. 벽은 관통하지 않습니다.
투척 순간부터 쿨타임 5초이며 횟수 제한이 없습니다. 빗나가도 쿨타임이 적용됩니다.
걸린 상대는 계속 걷고 점프할 수 있습니다. 당기는 순간 기존 관성에 힘을 더하며 충돌과 중력은 그대로 적용됩니다.
내가 상대 밧줄에 걸리면 조준점 주변에 빨간 X와 '밧줄에 걸림'이 표시됩니다. 연결된 동안 유지되고, 당겨져 연결이 끝나거나 밧줄이 풀리면 사라집니다.
벽이 사이를 가로막거나 16m 이상 벌어지면 풀립니다. 밀치기·발차기로 전환, 어느 쪽이든 추락·착석하면 연결이 해제됩니다.
추락이나 혼자 다시 앉기로 쿨타임을 초기화할 수 없습니다. 모두 앉아 종 경쟁이 끝나면 초기화됩니다.
앞선 사람과 뒤에 있는 사람 모두 맞힐 수 있습니다.
밧줄 묶음과 올가미는 기존 VARCO '할리갈리 데스런 · 1인칭 양손' 워크플로우에서 500포인트로 제작했습니다.
투척·상대에게 걸림·당기기 효과음 3종은 VARCO Sound에서 총 150포인트로 제작했습니다. 성공한 동작에 맞춰 한 번씩 재생하며, 빗나가면 명중·당기기 소리는 나지 않습니다.
상대가 쓰는 밧줄은 방향과 거리에 맞춰 들립니다. 내가 걸리거나 당겨질 때는 피격 소리가 또렷하게 들립니다. Previews/Lasso_Sounds.wav는 투척 → 명중 → 당기기 순서의 미리 듣기입니다.
효과음 동기화가 추가된 최신 빌드를 친구도 함께 사용해야 합니다.
1인칭과 상대 몸의 던지기·대기·당기기 동작은 직접 제작했습니다. VARCO 기본 모션은 사용하지 않습니다.
검증 결과: TestResults/lasso-validation.json, TestResults/lasso-network-validation.json


화면 안내
플레이 중에는 작은 조준점과 밧줄 아이콘을 표시합니다. 밧줄 테두리는 쿨타임, Q 표시는 사용 키입니다. 마취총은 제거했습니다.
맵과 AI 구성은 대기방에서 변경합니다. 혼자 하는 AI 대결도 같은 온라인 방을 사용하므로 인터넷 연결이 필요합니다.
시작 화면에서는 카드와 AI가 진행되지 않습니다. 방 만들기 / 초대코드로 참가의 뒤로 버튼 또는 Esc로 처음 선택 화면에 돌아옵니다.
카드 화면은 차례와 필요한 조작만 표시합니다. 과일 합계나 기립 정답은 알려주지 않습니다.


연습실
시작 화면의 연습실은 인터넷 없이 열립니다. 카드와 종 경쟁 없이 가만히 서 있는 AI 5명을 상대로 좌클릭 밀치기, F 발차기, Q 밧줄을 연습합니다. 밀려난 상대는 잠시 뒤 제자리로 돌아옵니다. R은 내 위치를 출발점으로 되돌리고 밧줄 쿨타임을 충전하지 않습니다. Esc → 시작 화면으로 나갑니다.


폐공장 기계실 (추가 맵)
방의 맵 목록에서 "폐공장"을 선택합니다. 기존 VARCO 실내 자산을 활용한 공장 코스입니다.
옆으로 밀어내는 컨베이어 → 왕복 발판 → 역방향 컨베이어와 교대 압착기 → 중간 체크포인트 → 높아지는 발판과 두 번째 왕복 발판 → 종으로 이어집니다.
경고등이 청록색이면 열림, 주황색이면 압착 예고, 빨간색이면 작동 중입니다. 압착기 양옆의 좁은 가장자리로 통과할 수도 있습니다.
프레스가 내려와 몸에 닿으면 즉시 추락 처리합니다. 앉은 상태도 동일합니다. 압착되거나 떨어지면 중간 체크포인트로 복귀하며, 체크포인트에 도착하기 전에는 출발점으로 돌아갑니다. R로도 같은 복귀를 사용할 수 있습니다.
최대 6인과 AI를 지원하며 출발선·첫 발판 간격은 모든 자리에서 동일합니다. 온라인 기계 동작은 공통 시각을 따르고 피격·종 판정은 방장이 처리합니다.
새 맵이 포함된 같은 빌드를 친구들도 사용해야 합니다.


첫걸음 — 엇박 왕복 발판
중간 대기 발판에 체크포인트가 있습니다. 두 운반 발판은 각각 5.6m를 반대 박자로 왕복합니다. 첫 발판에 올라 기다린 뒤 두 발판이 가까워지는 순간 두 번째로 갈아타고, 도착 발판과 가까워지면 종으로 향합니다.
운반 발판은 여러 명이 함께 탈 수 있는 폭이고 난간이 없어 밀치기와 밧줄로 서로 밀어낼 수 있습니다. 출발 시점과 관계없이 계속 왕복해 뒤쪽 플레이어가 기다리는 선두를 따라잡을 기회를 만듭니다.
떨어지거나 R을 누르면 저장된 대기 발판으로 돌아오며 운반 발판의 왕복 주기는 초기화되지 않습니다.

서프 수로 — 좌우 전환 코스 (2026-10-26)
낙하 후 180도 반전 → 연속 우회전 → 반대편 뱅크 진입 → 70도 좌회전 → 좁아지는 경사면과 공중 연결 → 110도 상승 곡면 → 종으로 이어집니다.
약 337m의 경사면을 배치했고, 마지막 공중 연결은 약 5m입니다. 자동 주행 시간은 검증 자료에만 기록하며 게임 화면에는 표시하지 않습니다.
청록색 CHECK 착지점 세 곳에서 복귀 위치를 저장합니다. R이나 추락 시 마지막 체크포인트로 돌아갑니다.
출발부의 수평 전기 칸막이는 유지했습니다. 각 구간을 순서대로 통과해야 종을 누를 수 있습니다.
참고: surf_utopia_njv의 연속 코스/체크포인트, surf_kitsune의 구간별 변화, surf_mesa_fixed의 곡면 구성. 모델과 텍스처는 기존 VARCO 자산을 재사용했습니다.
테스트는 같은 게임 물리를 사용하는 자동 주행입니다. 사람의 숙련도, 동선과 전투에 따른 실제 시간은 달라집니다.
