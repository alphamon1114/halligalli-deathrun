# 할리갈리 데스런 · Bell Run

과일 카드의 합을 직접 판단하고, 자리에서 일어나 장애물 코스 끝의 종을 차지하는 1인칭 경쟁 게임입니다. 최대 6명이며 친구와 AI를 함께 넣어 현재 인원으로 시작합니다.

## 다른 세션에서 이어가기

**먼저 [AGENTS.md](AGENTS.md)와 [작업 인계 기록](Docs/HANDOFF.md)을 읽으세요.** 인게임 맵 스튜디오, `.bellmap` 파일 공유와 방 참가자 자동 맵 전송을 지원합니다. 기존 왕의 회랑 양면 서프와 공식 맵은 유지합니다.

이 저장소의 루트가 Unity 프로젝트입니다. 별도의 하위 프로젝트 폴더를 만들 필요가 없습니다.

```powershell
git lfs install
git clone https://github.com/alphamon1114/halligalli-deathrun.git
cd halligalli-deathrun
git lfs pull
git lfs fsck
```

GitHub의 ZIP 다운로드 대신 Git + Git LFS로 복제하세요. 모델, 텍스처, 효과음, 미리보기는 LFS로 저장합니다. 비공개 저장소이므로 접근 권한이 있는 GitHub 계정이 필요합니다.

## 실행

1. Unity Hub에서 **Unity 6000.6.0f1**과 Windows Build Support를 설치하고 이 폴더를 추가합니다.
2. 패키지 설치와 에셋 가져오기가 끝날 때까지 기다립니다. `Packages/manifest.json`과 `packages-lock.json`이 포함돼 있습니다.
3. `Assets/HalliGalliMovement/Demo/BellRunCourse.unity`를 열고 Play를 누릅니다.
4. 방 만들기 → AI 추가 또는 친구 초대 → 맵 선택 → 시작 순서로 진행합니다. 연습실에는 공격 연습용 정지 상대가 있습니다.

| 기본 입력 | 기능 |
| --- | --- |
| WASD / 마우스 | 이동 / 시점 |
| Space / 휠 아래 | 점프 |
| Ctrl | 웅크리기 |
| 좌클릭 | 주먹 / 내 차례 카드 공개 |
| F | 발차기 |
| Q | 밧줄 투척 / 다시 눌러 당기기 |
| C | 레이스 아이템 사용 |
| E | 일어나기 / 앉기 / 종 |
| R | 체크포인트 복귀 |
| Esc | 메뉴 / 조작키 설정 |

Shift 달리기와 마비총은 제거된 상태입니다. 기본 이동은 4.5m/s이며 조작키를 바꿀 수 있습니다.

## 현재 코스

- **첫걸음**: 점프 코스와 서로 엇박으로 움직이는 마지막 운반 발판.
- **정상 쟁탈**: 한 봉우리를 돌아 오르는 공통 등반 코스와 일부 숏컷.
- **서프 수로**: 11개 편측 서프 구간. 구간 스킵 방지용 전기 칸막이.
- **폐공장**: 움직이는 발판, 컨베이어, 닿으면 복귀하는 프레스.
- **왕의 회랑**: 피라미드 내부의 25개 양면 삼각 서프, 5개 방, 4개 체크포인트. 왼쪽 또는 오른쪽을 선택해 같은 면으로 완주할 수 있습니다.
- **아이템 레이스**: 220m 연속 트랙과 32개 아이템 박스. 선두는 바나나·방어막·후방 큰 공을 각각 1/3 확률로, 추격자는 미사일 50%·직선 레이저 40%·바나나 10%로 획득합니다.

![왕의 회랑 양면 서프](Previews/Pyramid_Triangle_Choice.png)

아이템 레이스에서는 박스를 통과해 아이템 하나를 보관하고 **C**로 사용합니다. 미사일은 앞쪽 45m 안의 상대를 락온해 발사하며, 명중하면 몸이 공중제비를 돕니다. 카메라는 뒤집히지 않습니다. 바나나는 뒤에 설치해 상대를 미끄러뜨립니다. 큰 공은 뒤로 굴러가 상대를 밀어내며, 레이저는 최대 45m 직선으로 발사해 처음 맞은 상대를 밀어냅니다. 두 공격 모두 벽에 막힙니다. 방어막은 5초 동안 아이템 공격을 막습니다. 박스는 8초 후 재등장하며 착석·복귀·라운드 종료 시 보유 아이템과 효과가 해제됩니다. 카드·종 규칙은 그대로입니다.

## 직접 맵 만들기와 공유

1. 시작 화면 → **맵 만들기** → 왼쪽 두 번째 줄의 **금색 ‘부품 메뉴’**에서 부품을 고릅니다. 목록은 기본적으로 접혀 있으며 부품 선택 시 자동으로 닫힙니다. 맵을 클릭해 배치하세요. 메뉴는 버튼·Esc·맵 영역 클릭으로 닫을 수 있고, 닫는 클릭으로 부품이 배치되지는 않습니다. 시작 책상과 카드 규칙은 유지됩니다.
2. 발판·경사로·삼각 서프·체크포인트·이동 발판·컨베이어·프레스·위험 구역·도착 종·AI 경로점·**아이템 박스**를 사용합니다.
   부품에는 콘크리트·금속·고무 표면과 장치별 디테일이 자동 적용됩니다. 색상은 장식 포인트를 바꾸며 충돌 크기는 유지됩니다. 바닥 면적 테두리는 체크포인트만 표시합니다.
   **아이템 박스**는 부품 목록을 아래로 스크롤해 선택하고 바닥에 놓습니다. 크기는 고정이며 위치·수평 회전·색을 바꿀 수 있습니다. 닿으면 획득, **C**로 사용, 8초 후 재등장합니다. 공식 레이스와 같은 5종 아이템/확률을 사용하며 사용자 맵의 순위는 **종까지의 직선거리** 기준입니다. F8 검증에서도 사용하며 저장·파일 전달·자동 다운로드에 배치가 포함됩니다.
3. 기본은 **위에서 보기**입니다. **빈 바닥 드래그**로 화면 이동, **휠 또는 −/＋**로 확대·축소합니다. 부품은 클릭하면 선택만 하고 **더블클릭하면 가까이 보기**입니다. 선택한 부품의 손잡이를 드래그해서 이동·회전·크기를 바꿉니다.
   카메라 줄의 **위에서 / 사선 / 옆에서**, **전체 맵 / 선택 / 출발점 / 도착 종** 버튼으로 원하는 곳을 바로 봅니다. 시점 변경 시 선택한 부품을 중심에 유지합니다. 자유 비행은 **고급 비행 켜기**를 누른 경우에만 우클릭+WASD/QE로 사용하며, 이때도 휠은 이동 속도가 아니라 줌입니다. F는 선택 보기, G는 격자 맞춤입니다.
4. Ctrl+D 복제, Delete 삭제, Ctrl+Z/Y 실행 취소/다시 실행, Ctrl+S 저장. 오른쪽 속성에서 좌표·크기·색·장치 값을 정확히 입력할 수 있습니다.
5. **클리어 검증 F8**에서 혼자 출발점부터 이동하여 도착 종을 **E**로 울려야 저장·내보내기가 열립니다. 검증 중 낙하/R은 체크포인트 없이 출발점으로 돌아갑니다. F8로 편집에 복귀하며, 맵을 수정하면 다시 클리어해야 합니다.
6. **저장** 후 홈 → 방 만들기 → **사용자 맵**에서 선택합니다. 참가자는 맵을 자동으로 받고 검증을 마친 뒤 준비합니다. 맵을 바꾸면 다시 준비해야 합니다.

**파일로 전달:** 클리어 후 `내보내기`에서 `.bellmap` 파일 하나를 친구에게 보내세요. 친구가 `맵 만들기 → 가져오기`를 누르면 원본은 **받은 맵**에 보관되며, 재클리어 없이 방의 **사용자 맵**에서 선택할 수 있습니다. 함께 열리는 편집 사본은 새 ID의 미검증 초안이며 수정본을 저장·공유하려면 직접 클리어해야 합니다. `내 맵 → 받은 맵`에서 원본 파일을 다시 내보낼 수도 있습니다.

**방 참가 시 자동 다운로드:** 방장이 가진 사용자 맵을 참가자에게 자동 전송하고 파일 검사가 끝나야 준비할 수 있습니다. 받은 맵은 게임을 꺼도 보관되어 나중에 그 맵으로 방을 만들 수 있습니다. 동일한 내용의 맵이 있으면 캐시를 사용하며, 같은 이름이라도 내용이 다르면 별도 버전으로 보관합니다. 다운로드 맵은 제작자 클리어 인증이 아니라 받은 원본입니다. 파일 공유에는 서버 공인 인증이 없으므로 신뢰하는 사람의 파일을 사용하세요.

맵은 최대 **512개 부품 / 512KiB**, 종은 하나입니다. 외부 코드·모델·URL은 포함하지 않으며 게임에 내장된 부품만 사용합니다. 책상 앞 Z≥0 영역에서 제작합니다. AI는 작성한 경로점 순서로 이동하므로 복잡한 코스는 경로점도 배치하고 플레이로 확인하세요. 공개 맵 자료실과 공동 편집 기능은 포함하지 않습니다.
