# 할리갈리런

과일 카드의 합을 직접 판단하고, 자리에서 일어나 장애물 코스 끝의 종을 차지하는 1인칭 경쟁 게임입니다. 최대 6명이며 친구와 AI를 함께 넣어 현재 인원으로 시작합니다.

## Windows에서 플레이

1. [최신 배포 페이지](https://github.com/alphamon1114/halligalli-deathrun/releases/latest)에서 **BellRunLauncher.exe**를 받습니다. Unity나 별도 .NET 설치는 필요하지 않습니다.
2. 런처의 **설치 / 업데이트**를 누릅니다. 다운로드와 SHA-256·압축 해제 검증이 끝나면 **게임 실행**을 누릅니다.
3. 새 버전이 있으면 업데이트해야 실행할 수 있습니다. 매 실행 직전에 최신 배포를 다시 확인하며, 게임 실행 파일을 직접 열어도 자체 검사를 통과해야 합니다. 인터넷·GitHub 확인 실패 시에도 실행하지 않습니다.

게임은 `%LOCALAPPDATA%\BellRunLauncher` 아래 버전별로 설치됩니다. 사용자 맵·받은 맵은 기존 Unity LocalLow 저장 경로에 남고, 개인 설정도 유지합니다. 업데이트 실패 시 기존 설치는 보존하지만 최신 확인 없이 구버전을 실행하는 기능은 없습니다. 게임을 종료한 뒤 업데이트하세요.

화면·게임 창·런처에 표시하는 이름은 **할리갈리런**으로 통일합니다. 저장 호환성을 위해 Unity의 `companyName`/`productName`, PlayerPrefs 키, LocalLow 경로와 런처의 내부 파일명·설치 경로·업데이트 주소는 변경하지 않습니다.

현재 런처는 서명되지 않은 Windows x64 실행 파일입니다. Windows SmartScreen 경고가 나타날 수 있으므로 위 공식 배포 페이지에서 받은 파일인지 확인하세요. 버전 검사 기능이 없던 과거 배포본이나 수정된 실행 파일을 소급해서 차단하는 DRM은 아닙니다.

## 다른 세션에서 이어가기

**먼저 [AGENTS.md](AGENTS.md)와 [작업 인계 기록](Docs/HANDOFF.md)을 읽으세요.** 인게임 맵 스튜디오, `.bellmap` 파일 공유와 방 참가자 자동 맵 전송을 지원합니다. 현재 작업본에서는 왕의 회랑을 긴 활주·큰 곡선·고저차로 이어지는 다섯 유적으로 개편하고 서프 수로의 시각적 반복을 정리합니다. 미배포 변경과 검증 상태는 인계 기록을 따르세요.

이 저장소의 루트가 Unity 프로젝트입니다. 별도의 하위 프로젝트 폴더를 만들 필요가 없습니다.

```powershell
git lfs install
git clone https://github.com/alphamon1114/halligalli-deathrun.git
cd halligalli-deathrun
git lfs pull
git lfs fsck
```

GitHub의 ZIP 다운로드 대신 Git + Git LFS로 복제하세요. 모델, 텍스처, 효과음, 미리보기는 LFS로 저장합니다. 공개 저장소이므로 별도 접근 권한 없이 내려받을 수 있습니다.

## Unity 에디터에서 개발·실행

1. Unity Hub에서 **Unity 6000.6.0f1**과 Windows Build Support를 설치하고 이 폴더를 추가합니다.
2. 패키지 설치와 에셋 가져오기가 끝날 때까지 기다립니다. `Packages/manifest.json`과 `packages-lock.json`이 포함돼 있습니다.
3. `Assets/HalliGalliMovement/Demo/BellRunCourse.unity`를 열고 Play를 누릅니다.
4. 방 만들기 → AI 추가 또는 친구 초대 → 맵 선택 → 시작 순서로 진행합니다. 연습실에는 공격 연습용 정지 상대가 있습니다.

| 기본 입력 | 기능 |
| --- | --- |
| WASD / 마우스 | 이동 / 시점 |
| Space / 휠 아래 | 점프 |
| Ctrl | 웅크리기 |
| 좌클릭 | 한 손으로 빠른 밀치기 / 내 차례 카드 공개 |
| F | 오른발 발차기 · 수평으로 강하게 밀기 · 쿨타임 2초 |
| Q | 밧줄 투척 · 맞으면 자동으로 내 쪽으로 당기기 |
| C | 레이스 아이템 사용 |
| E | 일어나기 / 앉기 / 종 |
| R | 체크포인트 복귀 |
| Esc | 메뉴 / 조작키 설정 |

Shift 달리기와 마비총은 제거된 상태입니다. 기본 이동은 4.5m/s이며 조작키를 바꿀 수 있습니다.

1.0.9는 카드 공개 때 **0.18초의 짧고 작은 종이 효과음**을 추가합니다. 치찰음을 줄이고 낮은 음량으로 재생하며 입장·재접속·중복 상태 수신에는 과거 소리가 반복되지 않습니다. 1.0.8의 **내 캐릭터 꾸미기·치장 6종**과 **할리갈리런 / HALLIGALLI RUN** 홈 제목을 유지합니다.

1.0.7부터 **조작키 설정 → 마우스 감도**에서 슬라이더 또는 −/+로 **10~300%**를 5% 단위로 조절합니다. **100%**가 기존 감도이며 `감도 초기화`로 돌아갑니다. 변경은 즉시 적용·자동 저장되고, 맵/이동 프로필을 바꾸거나 게임을 재실행해도 유지됩니다. 일반 플레이와 맵 스튜디오의 1인칭 제작에 공통 적용합니다.

1.0.6부터 바리케이드는 **발차기 2회**로 파괴합니다. 첫 타격에 균열·흔들림이 생기고, 다른 플레이어의 타격도 합산됩니다. 좌클릭으로는 부술 수 없으며 기존 8초 자동 소멸은 유지합니다.

연습실은 **Esc 메뉴**에서 공격 연습 또는 서프 3단계(경사면 타기 / 낮은 서프로 갈아타기 / 높은 서프에 착지하기)를 고릅니다. 낙하·R은 선택한 단계 시작점으로 돌아오며, 서프 구역에서는 공식 서프 맵의 이동 설정을 그대로 사용합니다. 타이머·기록 경쟁은 없고 성공 여부만 안내합니다. 실제 이동/복귀 검사 **157/157 통과(2026-11-05)**이며 초보자 체감 난이도 평가는 별도입니다.

## 현재 코스

- **첫걸음**: 점프 코스와 서로 엇박으로 움직이는 마지막 운반 발판.
- **정상 쟁탈**: 한 봉우리를 돌아 오르는 공통 등반 코스와 일부 숏컷.
- **서프 수로**: 기존 11개 편측 서프 구간과 스킵 방지용 전기 칸막이를 유지합니다. 반복 패널·기둥·바닥 격자 대신 큰 배경 면과 간결한 위험 표시로 경로를 구분합니다.
- **폐공장**: 움직이는 발판, 컨베이어, 닿으면 복귀하는 프레스.
- **왕의 회랑**: 유적 진입·외벽 회랑·무너진 중앙 홀·수문·왕의 제단의 다섯 공간에서, 분리된 서프 사이를 날아 위층 또는 아래층의 면에 착지합니다. 큰 U자 경사를 반복하는 대신 발사 면 → 빈 공중 구간 → 독립된 착지 면으로 연결합니다. 청록색 표식은 다음 착지 면을 가리키며, 비행 경로를 가로지르는 장식은 없습니다. 이동 물리와 체크포인트 네 곳은 유지합니다.
  네 체크포인트 광장을 순서대로 지나면 공중에서도 자동 저장하며 R은 마지막 광장으로 복귀합니다. 발판마다 접촉하지 않아도 네 광장을 거쳐 종에 도착하면 누를 수 있습니다. 하단 점 네 개는 체크포인트 진행 표시입니다.
- **아이템 레이스**: 220m 연속 트랙과 32개 아이템 박스. 순위와 무관하게 미사일·바나나·바리게이트를 각각 1/3 확률로 획득합니다. 레이저·실드·굴러가는 공은 제거했습니다.
- **태엽 요새**: 점프·기계 함정·이동 발판을 섞은 160m 복합 코스입니다. 연속 점프와 창 → 우회전 → 엇박 프레스 2개와 화살 → 좌회전 → 기다렸다 타는 왕복 발판 → 좌회전 → 창·화살 혼합과 마지막 점프 순서입니다. 넓은 코너 체크포인트 3곳에서 재출발합니다. 화살은 0.4초 간격 고속 3연발이며 녹색 안전 시간에 통과하세요. 잘못 기립·좌석 복귀 중에도 실제 피격 시 리스폰합니다. 공식 맵 목록의 다음 페이지에서 선택합니다.

아이템 레이스에서는 박스를 통과해 아이템 하나를 보관하고 **C**로 사용합니다. 미사일은 바라보는 방향의 45m 안에서 **조준점에 가장 가까운 상대**를 실시간 락온하므로 선두도 뒤돌아 추격자를 공격할 수 있습니다. 조준을 옮기면 대상도 바뀌며, 발사한 뒤에는 발사 순간의 대상을 계속 추적합니다. 명중하면 기존 속도를 없애고 약 3.3m 높이로 띄우며, 1.4초 동안 수평 이동을 막고 몸만 공중제비를 돌립니다. 카메라는 뒤집히지 않습니다. 바나나는 뒤쪽 1.15m에 설치해 미끄러뜨립니다. 바리게이트는 바라보는 방향의 뒤쪽 3m에 설치되며, 현지 길 너비 약 1/3·높이 2.2m·두께 .6m로 8초간 막습니다. 점프·낙하 중에도 두 설치 아이템은 기존 뒤쪽 거리를 유지한 채 그 위치 아래의 실제 바닥에 즉시 놓입니다. 아래 바닥이 없거나 설치 면·공간이 안전하지 않으면 소비하지 않습니다. 바리게이트 양옆으로 우회할 수 있습니다. 박스는 8초 후 재등장하며 착석·복귀·라운드 종료 시 보유 아이템과 효과가 해제됩니다. 카드·종 규칙은 그대로입니다.

## 직접 맵 만들기와 공유

1. 시작 화면 → **맵 만들기** → 화면 아래 큰 부품 슬롯에서 고릅니다. **1~6**은 기본 발판·경사로·체크포인트·이동 발판·아이템 박스·도착 종입니다. 나머지는 **모든 부품**에서 선택합니다. 목록은 선택하면 닫히며, 닫는 맵 클릭으로 잘못 배치되지 않습니다. 시작 책상과 카드 규칙은 유지됩니다.
2. 발판·경사로·삼각 서프·체크포인트·이동 발판·컨베이어·프레스·위험 구역·도착 종·AI 경로점·**아이템 박스**를 사용합니다.
   부품에는 콘크리트·금속·고무 표면과 장치별 디테일이 자동 적용됩니다. 색상은 장식 포인트를 바꾸며 충돌 크기는 유지됩니다. 바닥 면적 테두리는 체크포인트만 표시합니다.
   **아이템 박스**는 아래 **5번 슬롯**에서 골라 바닥에 놓습니다. 크기는 고정이며 위치·수평 회전·색을 바꿀 수 있습니다. 닿으면 획득, **C**로 사용, 8초 후 재등장합니다. 공식 레이스와 같은 미사일·바나나·바리게이트 3종과 확률을 사용하며 사용자 맵의 순위는 **종까지의 직선거리** 기준입니다. F8 검증에서도 사용하며 저장·파일 전달·자동 다운로드에 배치가 포함됩니다.
3. 기본은 **1인칭 제작**입니다. **Tab 또는 맵 클릭**으로 조작을 시작하고, Tab/Esc로 마우스를 풀어 메뉴를 씁니다. **WASD + 마우스**로 이동·둘러보기, 비행 중 **Space/Ctrl**로 위·아래 이동합니다. **V**로 비행(노클립)과 실제 걷기·점프를 전환합니다. 걷기에서는 Space로 점프하며, 벽 안에서는 전환을 막습니다. 제작 중 점프 연습은 클리어 인증이 아닙니다.
4. **좌클릭**으로 미리보기 위치에 배치합니다. **Q**로 면에 붙이기/공중에 놓기를 명시적으로 전환하고, 공중 배치는 **휠**로 거리(2~60m)를 조절합니다. 0.5m 격자에 맞추며 점선과 바닥까지 높이를 표시합니다. 바닥이 없으면 Y0 기준임을 표시합니다. **R**은 90도 회전, **우클릭**은 조준 부품 선택·설정, **Delete**는 조준 부품 삭제입니다. 크기 3단계·복제·방향 이동 버튼과 이동 발판 방향/거리/빠르기 설정을 유지합니다.
   **전체 보기**로 전환하면 우클릭 드래그 회전, 가운데/빈 바닥 드래그 팬, 휠 줌(공중 배치 중에는 거리 조절)을 사용합니다. 1인칭으로 돌아오면 이전 위치를 복구합니다. Ctrl+D 복제, Ctrl+Z/Y 실행 취소/다시 실행, Ctrl+S 저장. 자세히의 W/E/R 축 도구는 전체 보기에서 사용합니다. 출발 데크·마지막 종은 삭제할 수 없습니다.
5. **클리어 검증 F8**에서 혼자 출발점부터 이동하여 도착 종을 **E**로 울려야 저장·내보내기가 열립니다. 검증 중 낙하/R은 체크포인트 없이 출발점으로 돌아갑니다. F8로 편집에 복귀하며, 맵을 수정하면 다시 클리어해야 합니다.
6. **저장** 후 홈 → 방 만들기 → **사용자 맵**에서 선택합니다. 참가자는 맵을 자동으로 받고 검증을 마친 뒤 준비합니다. 맵을 바꾸면 다시 준비해야 합니다.

**파일로 전달:** 클리어 후 `내보내기`에서 `.bellmap` 파일 하나를 친구에게 보내세요. 친구가 `맵 만들기 → 가져오기`를 누르면 원본은 **받은 맵**에 보관되며, 재클리어 없이 방의 **사용자 맵**에서 선택할 수 있습니다. 함께 열리는 편집 사본은 새 ID의 미검증 초안이며 수정본을 저장·공유하려면 직접 클리어해야 합니다. `내 맵 → 받은 맵`에서 원본 파일을 다시 내보낼 수도 있습니다.

**방 참가 시 자동 다운로드:** 방장이 가진 사용자 맵을 참가자에게 자동 전송하고 파일 검사가 끝나야 준비할 수 있습니다. 받은 맵은 게임을 꺼도 보관되어 나중에 그 맵으로 방을 만들 수 있습니다. 동일한 내용의 맵이 있으면 캐시를 사용하며, 같은 이름이라도 내용이 다르면 별도 버전으로 보관합니다. 다운로드 맵은 제작자 클리어 인증이 아니라 받은 원본입니다. 파일 공유에는 서버 공인 인증이 없으므로 신뢰하는 사람의 파일을 사용하세요.

맵은 최대 **512개 부품 / 512KiB**, 종은 하나입니다. 외부 코드·모델·URL은 포함하지 않으며 게임에 내장된 부품만 사용합니다. 책상 앞 Z≥0 영역에서 제작합니다. AI는 작성한 경로점 순서로 이동하므로 복잡한 코스는 경로점도 배치하고 플레이로 확인하세요. 공개 맵 자료실과 공동 편집 기능은 포함하지 않습니다.
